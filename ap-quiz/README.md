# 応用情報 科目Aドリル（午前クイズアプリ）

応用情報技術者試験の科目A（旧 午前）対策用の、オリジナル4択問題 385 問のWebアプリです。
IPA公開の過去問題（令和2〜7年度）とシラバスVer.7.2で問われたテーマをもとに作成しています（過去問題の問題文そのものではありません）。

- 公開版（claude.ai Artifact）：https://claude.ai/artifact/2uu8R4RsLQJYssnXwgMZaN
- 単体で動くHTML：`dist/index.html`（ブラウザで開くだけで使えます）

## 機能

- **模擬試験**：本番と同じ配分（テクノロジ50・マネジメント10・ストラテジ20）の80問、150分タイマー、問題一覧・見直しフラグ、60点合格ライン判定
- **分野別演習**：17分野から選択、出題数、「未解答だけ」「間違えたことがある問題だけ」で絞り込み
- **ランダム10問**、**間違えた問題の復習**、**ブックマーク**
- 解答直後に解説と学習ノートの対応章を表示。選択肢の並びは毎回シャッフル
- 分野別の正答率と模擬試験の記録。進捗は端末に保存（claude.ai上ではアカウントにも保存）

## 構成

| ファイル | 内容 |
|---|---|
| `questions/*.js` | 問題データ（`{id, c:分野, q, o:[正解, 誤答×3], a:0, e:解説, r:学習ノートの章}`） |
| `app.html` | 画面とロジック |
| `build.py` | 問題データを埋め込んで `dist/index.html` を生成 |

問題を追加するときは `questions/` に追記して `python3 build.py` を実行します（正解は先頭 `a:0` に書き、表示時にシャッフルされます）。
