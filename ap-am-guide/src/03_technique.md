## 1. 消去法の5パターン

四肢択一では、正解を知らなくても **誤りの選択肢を消す** ことで正答率を上げられます。

| パターン | 見分け方 | 例 |
|---|---|---|
| ①定義の入れ替え | 2つの用語の説明が入れ替わっている | 「フェールセーフ：機能を縮小して運転を継続する」→ それはフェールソフト |
| ②主語・対象の取り違え | 「誰の」「どちらの」が逆 | 「デジタル署名は受信者の秘密鍵で作成する」→ 送信者の秘密鍵 |
| ③範囲・数値のずれ | 数値や範囲が少しずれている | 「プライベートアドレス 172.32.0.0/12」→ 172.16.0.0/12 |
| ④言い過ぎ（断定） | 「必ず」「すべて」「常に」「一切」 | 「暗号化すれば改ざんは必ず防げる」→ 暗号化は改ざん検知ではない |
| ⑤別分野の説明 | 問われている概念とは別の分野の説明 | 「SLAの説明」に「組織内部の部門間の合意」→ それはOLA |

:::how 選択肢の読み方
**①問題文の最後（「適切なもの」か「適切でないもの」か）に印を付ける。② 選択肢ごとに〇×△を付ける。③ △が残ったら、①〜⑤のパターンで消す。** 「適切でないもの」を選ぶ問題で、うっかり適切なものを選ぶミスが最も多いので、①は必ず行います。
:::

## 2. 問いの形式別の解き方

| 形式 | 解き方 |
|---|---|
| 「〇〇の説明はどれか」 | 〇〇の定義を一言で思い浮かべてから選択肢を見る。選択肢の中に、他の用語の定義が並んでいることが多い |
| 「〇〇に該当するものはどれか」 | 〇〇の具体例を思い出す。抽象的な定義ではなく事例で判断 |
| 「適切な組合せはどれか」 | 確実にわかる1つの要素で、選択肢を2つに絞る |
| 計算問題 | 式を書いてから計算。選択肢の桁を見て、概算で絞る |
| 図・表を読む問題 | 先に問題文の最後を読み、何を求めるかを確認してから図表を見る |
| 擬似言語・流れ図 | 小さな値で1〜2回だけトレースする |

## 3. 計算問題の時短テクニック

- **2のべき乗は暗記**：2^10＝1,024≒10^3、2^20≒10^6、2^30≒10^9。
- **概算で選択肢を絞る**：0.99×0.98 は「1−0.01−0.02＝0.97」で近似できる（小さい値どうしの積は無視）。
- **選択肢を代入する**：「n はいくつか」は、選択肢の値を式に入れて成り立つものを選ぶ。
- **単位をそろえてから計算**：バイト↔ビット（×8）、ミリ秒↔秒、人月↔人日。
- **割合は分数で**：利用率0.8なら ρ/(1−ρ)＝0.8/0.2＝4。小数より分数のほうが速い。

## 5. CBT方式（2026年度〜）の画面操作

- 問題の **見直しフラグ** と **問題一覧** を使い、2周目に回す問題をすぐ探せるようにする。
- 試験画面の **メモ機能・電卓機能** と、配布される **メモ用紙1枚** が使える（2026年度の案内）。計算はメモ用紙に式を書く。
- 科目Aは試験終了後に **得点が画面に表示される**。
- 模擬試験（Web版）は、見直しフラグ・問題一覧・タイマーを本番に近い形にしてあるので、操作の練習に使える。
