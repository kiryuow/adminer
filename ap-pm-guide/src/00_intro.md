科目B（旧 午後）は、11問から5問を選んで解く記述式の試験です。1問20点、合計60点以上で合格基準です。知識の量よりも、**問題文から根拠を見つけ、問われたことに過不足なく答える力** で点数が決まります。

この攻略本は、学習ノート第17章と午後対策シートで学んだ「型」を、本番で確実に使えるようにするための本です。

## この本の構成

| 章 | 内容 |
|---|---|
| 第1章 | 得点戦略：60点の取り方、部分点、当日の問題選択の判断基準 |
| 第2章 | 本文の読み方：設問から読む手順、マーキングのルール、下線・空欄・表の扱い |
| 第3章 | 書き方：減点される解答とその直し方（添削例） |
| 第4章 | 分野別の知識テンプレ：本番でそのまま使える「型」の知識 |
| 第5章 | 解き方の実演：模擬試験の問1と問11を、思考の順番どおりに解く |
| 第6章 | 学習計画と当日の動き |

:::note 採点の仕組みについて
IPAは記述式の採点基準を公開していませんが、解答例と採点講評が公開されています。本書の「部分点」の考え方は、解答例に含まれる要素（キーワード）を満たしているかで採点されるという前提で、自己採点するときの目安を示したものです。
:::
