## 1. 残り期間別の計画

| 残り期間 | やること |
|---|---|
| 2か月 | 選択分野を決める（午後対策シートの自己診断）→ 各分野で午後対策シートのミニ演習 → IPA過去問を分野ごとに直近3回分 |
| 1か月 | 本命4分野＋問1を、直近5回分まで広げる。1問30分を計って解く。間違いノートを付ける |
| 2週間 | 模擬試験（科目B）を本番どおり150分で解く。第3章の添削例と自分の解答を比べる |
| 1週間 | 間違いノートと第4章の知識テンプレだけを見直す。新しい過去問は解きすぎない |

## 2. 採点講評の使い方

IPAの採点講評は、受験者がどこで間違えたかを教えてくれる貴重な資料です。

1. 解き終わったら、まず解答例で採点する。
2. 次に採点講評を読み、「正答率が低かった設問」に印を付ける。
3. その設問で、自分も同じ間違いをしていないか確認する。
4. 講評の「〜を理解してほしい」という一文を、間違いノートに書き写す。

:::note 採点講評の頻出フレーズ
「設問で問われていることを正しく理解した上で」「本文中の記述に着目して」「具体的に」「用語だけを挙げた解答が散見された」――この4つを意識するだけで、多くの減点を防げます。
:::

## 3. 本番150分の動き（CBT方式）

| 時間 | やること |
|---|---|
| 0〜5分 | 問2〜問11の題材と設問をざっと見て、4問を選択する（画面で選択の操作） |
| 5〜35分 | 問1（必須） |
| 35〜135分 | 選択問題4問（得意な順に、1問25分） |
| 135〜150分 | 空欄を埋める。選択の操作と字数を確認する |

- 記述はキーボードで入力する。日本語変換の誤り（同音異義語）に注意。
- メモ用紙は、本文の段落番号と記号のメモ（第2章）、計算に使う。
- 1問で詰まったら、設問の **記号選択・穴埋めだけ先に** 解いて次へ進む。

## 4. この攻略本の後に

- **模擬試験（Web版）**：科目Bを本番と同じ画面の流れ（問題選択→解答入力→自己採点）で練習できます。
- **午後対策シート**：記録シートで、演習の得点と間違いの理由を記録し続けましょう。
