ここでは、別冊の **模擬試験 問題冊子** の問1と問11を使って、第2〜4章の手順を実際に当てはめます。先に自分で解いてから読むと効果的です。

## 実演1：問1 情報セキュリティ（ランサムウェア）

### ステップ1：設問を先に読む（2分）

| 設問 | 何を問われているか | 印を付けた条件 |
|---|---|---|
| 設問1 | 下線①（LANケーブルを抜いた）の **目的** | 25字以内 → 文末「〜ため」 |
| 設問2 | 表の空欄a：認証の強化策 | 10字以内の **字句** |
| 設問3 | 表の空欄b：退職者への手順 | 15字以内 |
| 設問4 | 下線②の **理由** | **本文中の事実を踏まえて**、35字以内 |
| 設問5 | 管理上の問題点を **二つ** | 各20字以内 |

### ステップ2：本文を読む（10分）

第2章のマーキングで読むと、次の箇所に印が付きます。

- 「VPN装置の認証は、利用者IDとパスワードだけ」→ ＿（弱点）→ 設問2の根拠
- 「退職者の利用者IDでVPN接続」「退職後も削除されていなかった」→ ＿ → 設問3・設問5の根拠
- 「同じLANに接続したNASに…NAS上のバックアップも暗号化」→ ＿ → 設問4の根拠
- 「ファームウェアは3か月前に公開…適用されていなかった」→ ＿ → 設問5の根拠

### ステップ3：設問を解く

- **設問2**：「IDとパスワードだけ」が弱点 → パスワード以外の要素を追加 → **多要素認証**。
- **設問3**：根拠は(1)「退職後も削除されていなかった」→ **利用者IDを速やかに削除**。
- **設問1**：LANから切り離す目的は、初動の定番 → **他の機器への感染の拡大を防ぐため**（16字）。
- **設問4**：条件「本文中の事実を踏まえて」→ (3)の事実を使う → **LANに接続したNAS上のバックアップも暗号化されてしまったため**。一般論（ランサムウェアはバックアップも狙う）だけでは条件を満たさない。
- **設問5**：「二つ」→ 異なる要素を2つ。本文の(1)と(4)から **①修正ファームウェアの未適用 ②退職者IDの未削除**。

:::point この問題から学ぶこと
5つの設問の根拠は、すべて本文の〔インシデントの発生〕の(1)〜(4)にありました。問1は「本文の事実→弱点→対策」が1対1で対応するように作られていることが多いです。
:::

## 実演2：問11 システム監査（経費精算）

### ステップ1：設問を先に読む

- 設問1：予備調査の結果(2)から想定される **不正のリスク**（40字）
- 設問2：表の [ a ]：「承認の職務分掌」を確かめる **監査手続**（40字）
- 設問3：表の [ b ]：経理部の説明を **裏付ける監査証拠を含めて**（40字）
- 設問4：監査人の対応（記号）

### ステップ2：リスク → コントロール → 証拠 の順に整理

| 本文の事実 | リスク | 確かめるべきコントロール | 監査証拠 |
|---|---|---|---|
| 申請者本人を代理承認者に指定できる | 自己承認による不正な経費の支払 | 申請者と承認者が別人であること | 承認記録（申請者IDと承認者ID） |
| 代理承認者の解除手続がない | 不要な権限が残る | 定期的な見直し・解除 | 代理承認者一覧と人事異動の記録 |
| 経理部は全件確認していると「説明」 | 説明どおり実施されていない | 支払前の照合 | 照合済みの記録（チェック記録） |

### ステップ3：テンプレートで書く

- **設問2**：「（承認記録）を（閲覧）し、（申請者と承認者が同一の申請がないか）を確かめる」
- **設問3**：「（確認済みの記録）を（サンプリングで閲覧）し、（全件の照合が実施されているか）を確かめる」── 「説明」は監査証拠として弱いので、**記録で裏付ける** のがポイント。
- **設問4**：監査人は改善を「指摘・提案」する立場 → **イ**。削除させる・自ら削除する・停止させる は監査人の権限を超える。

:::how 監査の問題を解く合言葉
**「リスクは何か → それを防ぐコントロールは何か → それが動いている証拠は何か」**。この3段階を表に書いてから作文すると、監査要点と監査手続がずれません。
:::
