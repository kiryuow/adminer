<p><b>図書館の貸出管理システムに関する次の記述を読んで、設問に答えよ。</b></p>
<div class='bcase'>
<p>Ｒ市立図書館は、貸出管理システムを再構築している。主な業務ルールは次のとおりである。<br>(1) 利用者は利用者番号で識別する。1人の利用者は同時に最大10冊まで借りられる。<br>(2) 図書は資料番号で識別する。同じ書名の本が複数冊ある場合、1冊ごとに資料番号を付ける。<br>(3) 1回の貸出で1冊を貸し出し、返却日が記録されるまで貸出中とする。</p>
<h4>〔表の構造〕</h4>
<p>利用者（利用者番号, 氏名, 住所）<br>書誌（ISBN, 書名, 著者名）<br>資料（資料番号, ISBN）<br>貸出（貸出番号, 利用者番号, 資料番号, 貸出日, 返却期限日, 返却日）<br>※下線の代わりに、各表の最初の列を主キーとする。資料.ISBN、貸出.利用者番号、貸出.資料番号は外部キーである。返却されていない貸出の返却日は NULL とする。</p>
<h4>〔SQL文〕</h4>
<pre>-- 現在貸出中の冊数が10冊に達している利用者の利用者番号を求める
SELECT 利用者番号
  FROM 貸出
 WHERE [ a ]
 GROUP BY 利用者番号
[ b ] COUNT(*) &gt;= 10

-- 返却期限を過ぎて未返却の資料の書名を求める（基準日は :today）
SELECT DISTINCT 書誌.書名
  FROM 貸出
  JOIN 資料 ON 貸出.資料番号 = 資料.資料番号
  JOIN 書誌 ON [ c ]
 WHERE 貸出.返却日 IS NULL
   AND 貸出.返却期限日 &lt; :today</pre>
</div>

<div class='bq'><b>設問1</b>　「書誌」と「資料」の関係の多重度（カーディナリティ）を答えよ。また、そのように判断した根拠となる業務ルールを本文中の番号で答えよ。</div>
<div class='bq'><b>設問2</b>　SQL文中の [ a ] 〜 [ c ] に入れる適切な字句を答えよ。</div>
<div class='bq'><b>設問3</b>　「貸出」表に「書名」の列を追加した場合に生じる問題を、35字以内で述べよ。</div>
<div class='bq'><b>設問4</b>　業務ルール(1)の「最大10冊まで」の制約を、貸出の登録時に確認するために利用できるSQL文は、〔SQL文〕のどちらか。前者・後者で答えよ。</div>
