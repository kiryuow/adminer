<p><b>在庫データの区間集計（累積和）に関する次の記述を読んで、設問に答えよ。</b></p>
<div class='bcase'>
<p>Ｎ社の倉庫では、1日ごとの出荷数を配列 ship に記録している。ship[i] は i 日目の出荷数である（i は 1 から n、配列の添字は1から始まる）。利用者は「s 日目から t 日目までの出荷数の合計」を何度も問い合わせる。</p>
<p>単純な方法では、問合せのたびに ship[s] から ship[t] までを足し合わせるため、1回の問合せに最大 n 回の加算が必要になる。そこで、あらかじめ累積和の配列 acc を作っておき、各問合せを1回の引き算で答える方法を考えた。acc[0] ＝ 0 とし、acc[i] は 1 日目から i 日目までの出荷数の合計とする。</p>
<pre>○makeAcc(整数型の配列: ship, 整数型: n)
  acc[0] ← 0
  for (i を 1 から n まで 1 ずつ増やす)
    acc[i] ← [ ア ]
  endfor

○整数型: query(整数型: s, 整数型: t)
  return [ イ ]</pre>
<p>例えば ship ＝ {5, 3, 8, 2, 6} （n ＝ 5）のとき、acc は {0, 5, 8, 16, 18, 24} となる。</p>
</div>

<div class='bq'><b>設問1</b>　プログラム中の [ ア ] に入れる適切な字句を答えよ。</div>
<div class='bq'><b>設問2</b>　プログラム中の [ イ ] に入れる適切な字句を答えよ。</div>
<div class='bq'><b>設問3</b>　本文の例で、query(2, 4) が返す値を答えよ。</div>
<div class='bq'><b>設問4</b>　問合せが q 回あるとき、単純な方法と累積和を使う方法の、問合せ処理全体の計算量をそれぞれオーダー記法で答えよ。ただし、累積和を作る処理を含めて考えること。</div>
