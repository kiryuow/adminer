# 応用情報技術者試験 午後（科目B）対策シート

学習ノート第17章の実践編。記述式を「設問の型 → 答え方の型」で解くためのシート集（A4・35ページ）。

- PDF: [`dist/ap-pm-sheets.pdf`](dist/ap-pm-sheets.pdf)
- 原稿: `src/*.md`（ビルドは学習ノートと同じ `python3 build.py`）

## 内容

| シート | 内容 |
|---|---|
| はじめに | 3ステップの演習サイクル、CBT方式の注意、過去問の入手 |
| 共通 | 記述の4原則、設問の型と答え方の型、字数調整、時間配分、選択分野の自己診断 |
| 問1〜問11 | 出題テーマ（R2〜R7）、必須知識チェックリスト、頻出設問と答え方、採点講評からの注意点、オリジナルのミニ演習（解答例・解説つき） |
| 記録 | 過去問演習計画表、演習記録、間違いノート、試験直前チェック |

「採点講評からの注意点」は、IPA公開の令和2〜7年度の採点講評を分野別に整理・要約したものです。ミニ演習の事例はすべてオリジナルです。
