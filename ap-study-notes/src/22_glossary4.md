## 17. システム戦略

| 用語 | 意味 |
|---|---|
| CDO | 最高デジタル責任者。DXを推進する役員（Chief Data Officer の意味で使うこともある） |
| IT投資マネジメント・ITポートフォリオ | IT投資を計画・評価・管理すること ／ IT投資を目的やリスクで分類し、全体の配分を最適化する考え方 |
| シェアードサービス | グループ企業の経理・人事などの共通業務を1つの組織に集約して効率化する |
| 経営ダッシュボード | 経営の重要指標（KPI）をグラフなどで一覧表示する画面 |
| エンタープライズサーチ | 社内に散らばる文書やデータを横断的に検索する仕組み |
| KMS | 知識管理システム。社内の知識・ノウハウを蓄積・共有する |
| ザックマンフレームワーク・TOGAF | EAの代表的な枠組み（視点と観点の表で整理する） ／ The Open Groupが定めたEAの枠組み |
| EAI | 社内の異なるシステムどうしを連携・統合するためのミドルウェアや手法 |
| EAの成果物 | 業務説明書、WFA（業務流れ図）、データ定義表、情報体系整理図、ネットワーク構成図 など |
| プロセスマイニング | システムのログから実際の業務の流れを再現し、ボトルネックや非効率を見つける手法 |
| IDEF | 業務の機能やデータをモデル化する手法の総称（IDEF0は機能モデル） |
| ソブリンクラウド | データの保管場所や管理を自国の法律の範囲内に限定したクラウド |
| クラウドネイティブ・クラウドバイデフォルト | クラウドの利点を最大限に生かして設計すること ／ 政府がシステムを作るとき、クラウドを第一候補とする原則 |
| イミュータブルインフラストラクチャ | 稼働中のサーバは変更せず、変更が必要なら新しいサーバを作って置き換える運用 |
| ホスティング・ハウジング | 事業者のサーバを借りる ／ 自社のサーバを事業者のデータセンタに置かせてもらう |
| BYOD | 個人所有のスマートフォンなどを業務に使うこと。MDMなどで管理する |
| ゲーミフィケーション | ゲームの要素（ポイント、ランキング）を取り入れて、利用や学習の意欲を高める |
| LMS | 学習管理システム。eラーニングの配信と受講状況の管理を行う |

## 18. システム企画

| 用語 | 意味 |
|---|---|
| BABOK | ビジネスアナリシス（業務の課題を分析し、解決策を定義する活動）の知識体系 |
| Fit to Standard・OOTB | 業務をパッケージの標準機能に合わせる（カスタマイズを減らす） ／ 製品を購入してすぐに使える状態 |
| PBP（回収期間）・DCF法 | 投資額を回収するまでの期間 ／ 将来のキャッシュフローを現在価値に割り引いて評価する方法 |
| DPP（割引回収期間法） | 割り引いたキャッシュフローで回収期間を計算する方法 |
| 要求工学 | 要求の獲得・分析・仕様化・検証・管理を体系的に行う工学 |
| 現状指向型・目的指向型アプローチ | 現状の業務の分析から要求をまとめる ／ あるべき目的から要求を導く |
| 内外作基準 | 自社で作るか（内作）、外部に委託するか（外作）を判断する基準 |
| IFB（入札募集） | 価格を中心に、入札を募集する文書 |
| 一般競争入札・企画競争入札 | 条件を満たす誰でも参加でき、主に価格で決める ／ 提案内容（企画）で選ぶ |
| 総合評価落札方式 | 価格と技術などの点数を総合して落札者を決める方式。**加算方式**（価格点＋技術点）など |
| WTO政府調達協定 | 一定額以上の政府調達で、外国企業にも公平に参加の機会を与える国際協定 |
| OEM・ODM | 他社ブランドの製品を製造する ／ 設計から製造までを請け負う |
| ソフトウェアのサプライチェーンマネジメント | 使用しているOSSや外部部品の出どころ・脆弱性・ライセンスを管理すること（SBOM） |
| ライセンス契約の用語 | **ランニングロイヤリティ**（売上などに応じて払い続ける使用料）、**サブライセンス**（許諾を受けた者がさらに第三者に許諾）、**グラントバック**（改良技術を元の権利者に許諾する義務） |
| タイムアンドマテリアル契約 | 作業時間と材料費の実費に基づいて支払う契約 |

## 19. 経営戦略マネジメント

| 用語 | 意味 |
|---|---|
| シナジー効果 | 複数の事業を組み合わせることで、個別に行うより大きな効果が生まれること |
| 規模の経済・範囲の経済 | 生産量が増えるほど単位あたりのコストが下がる ／ 複数の事業で資源を共有してコストが下がる |
| 経験曲線 | 累積生産量が2倍になるごとに、単位コストが一定の割合で下がる現象 |
| ダイナミックケイパビリティ | 環境の変化に応じて、自社の資源を組み替え、変革する能力 |
| チェンジマネジメント | 組織の変革を、人の抵抗を和らげながら計画的に進める手法 |
| IPランドスケープ | 特許などの知財情報を分析して、経営戦略・事業戦略に生かす手法 |
| サーキュラーエコノミー | 製品や資源を回収・再利用して、廃棄を出さない循環型の経済 |
| VUCA | 変動性・不確実性・複雑性・曖昧性が高く、将来を予測しにくい環境 |
| TCFD | 気候変動が企業の財務に与える影響を開示するための国際的な枠組み |
| エコシステム | 複数の企業や顧客が、相互に依存しながら価値を生み出す経済の仕組み |
| インキュベーター | 起業家やベンチャー企業の創業・成長を支援する組織 |
| 相対的市場シェア | 自社のシェア ÷ 最大の競合企業のシェア（PPMの横軸） |
| 市場調査の手法 | **コンジョイント分析**（製品の属性の組合せから、顧客が重視する要素を分析）、**エスノグラフィー**（現場で行動を観察する）、**クロス集計**（2つ以上の項目を掛け合わせて集計） |
| 価格感度測定法（PSM） | 「高すぎる」「安すぎる」などの質問から、受け入れられる価格帯を求める |
| バリュープロポジション | 顧客に提供する独自の価値の提案（なぜ自社を選ぶべきか） |
| ブランドアイデンティティ | 企業がブランドとして顧客に持ってほしいイメージ |
| マーチャンダイジング | 適切な商品を、適切な量・価格・時期・場所で提供するための計画 |
| LTV（顧客生涯価値） | 1人の顧客が、取引期間全体を通じて企業にもたらす利益 |
| コンバージョン率（CVR）・リテンション率 | サイト訪問者のうち購入などに至った割合 ／ 顧客が継続して利用している割合 |
| サービスブループリント | サービスの提供過程を、顧客の行動と裏側の業務まで含めて図にしたもの |
| 計画的陳腐化 | 新製品を定期的に出して、旧製品を古く感じさせ買替えを促すこと |
| コモディティ化 | 製品の差がなくなり、価格だけで選ばれるようになること |
| カニバリゼーション | 自社の新製品が、自社の既存製品の売上を奪ってしまうこと |
| 需要の価格弾力性 | 価格が変化したときに、需要がどれだけ変化するかの度合い |
| コストプラス法 | 原価に一定の利益を上乗せして価格を決める方法 |
| ボランタリーチェーン・フランチャイズチェーン | 独立した小売店が共同で仕入れなどを行う ／ 本部が加盟店にブランドやノウハウを提供し対価を得る |
| インターネット広告 | **リスティング広告**（検索キーワードに連動）、**ジオターゲティング広告**（位置に連動）、**成功報酬型広告**（アフィリエイト）、**オプトインメール広告** |
| SEO・LPO | 検索結果で上位に表示されるようにする工夫 ／ 広告から最初に訪れるページ（ランディングページ）を改善して成果を高める |
| デジタルサイネージ | ディスプレイを使った電子看板 |
| バイラルマーケティング | 口コミで情報が広がるように仕掛けるマーケティング |
| ビジネスモデルキャンバス | 顧客・価値提案・チャネル・収益の流れなど9つの要素でビジネスモデルを1枚に整理する |
| フィージビリティスタディ | 計画が技術的・経済的に実現可能かを事前に調査すること |
| HHI | 市場の各企業のシェアの2乗の合計。市場の集中度（寡占度）を表す |
| バリューエンジニアリング（VE） | 製品の機能とコストの比（価値）を高めるよう、機能を分析して改善する手法 |
| TQM | 全社的に品質管理に取り組む経営手法 |
| ECR | 製造業者と小売業者が協力して、消費者に効率的に商品を提供する取組み |
| EIP | 社内の情報やシステムへの入口を1つにまとめたポータルサイト |

## 20. 技術戦略マネジメント

| 用語 | 意味 |
|---|---|
| プロダクトイノベーション・プロセスイノベーション | 新しい製品を生み出す革新 ／ 製造方法など工程の革新 |
| ラディカルイノベーション | 既存の技術や市場を根本から変える革新（インクリメンタル＝漸進的と対比） |
| リーンスタートアップ | 最小限の製品（**MVP**）を素早く作り、顧客の反応から学んで改善を繰り返す起業の手法 |
| イノベーター理論 | 新製品の普及を、イノベーター → アーリーアダプター → アーリーマジョリティ → レイトマジョリティ → ラガードの5層で説明する |
| 技術のSカーブ | 技術の性能は、初めはゆっくり、その後急速に向上し、やがて限界に近づいて頭打ちになる |
| CVC | 事業会社が自社の戦略のために設立するベンチャー投資の組織 |
| PoV・PoB | 価値があるかの実証 ／ ビジネスとして成り立つかの実証（PoCの次の段階） |
| TLO | 大学の研究成果を特許化し、企業に技術移転する機関 |
| 防衛特許 | 他社に特許を取られて自社が使えなくなるのを防ぐため、出願しておく特許 |
| アイディアソン・ハッカソン | 短期間で集中してアイデアを出し合うイベント ／ 短期間でプログラムを作り上げるイベント |
| コンカレントエンジニアリング | 設計・生産準備などの工程を並行して進め、開発期間を短縮する |
| メイカームーブメント | 3Dプリンターなどを使い、個人がものづくりを行う動き |

## 22. 企業活動

### 経営・組織論

| 用語 | 意味 |
|---|---|
| パーパス経営 | 企業の社会的な存在意義（パーパス）を軸にした経営 |
| 統合報告書 | 財務情報と、環境・社会・ガバナンスなどの非財務情報をまとめた報告書 |
| コーポレートガバナンス・コード | 上場企業が守るべき企業統治の原則（東京証券取引所） |
| OODAループ | 観察（Observe）→ 状況判断（Orient）→ 意思決定（Decide）→ 行動（Act）を素早く繰り返す意思決定の手法 |
| 人材育成の手法 | **コーチング**（質問で相手の答えを引き出す）、**メンタリング**（先輩が助言・支援する）、**ジョブローテーション**、**アダプティブラーニング**（個人の理解度に合わせた学習） |
| コンピテンシー | 高い成果を上げる人に共通する行動特性 |
| エンゲージメント・リテンション | 社員の組織への愛着・貢献意欲 ／ 優秀な人材の流出を防ぐ取組み |
| エンパワーメント | 現場の社員に権限を与え、自律的な判断を促すこと |
| DE&I・ウェルビーイング | 多様性・公平性・包摂性 ／ 身体的・精神的・社会的に良好な状態 |
| 動機づけの理論 | **マズローの欲求段階説**（生理的→安全→社会的→承認→自己実現）、**ハーズバーグの動機づけ・衛生理論**（満足を生む要因と不満を防ぐ要因は別）、**マグレガーのXY理論**、**期待理論** |

### 会計・財務

| 用語 | 意味 |
