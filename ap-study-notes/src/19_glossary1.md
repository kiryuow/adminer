## 1. 基礎理論

### 離散数学

| 用語 | 意味 |
|---|---|
| 単精度／倍精度浮動小数点数 | IEEE 754 で32ビット（単精度）／64ビット（倍精度）で表す浮動小数点数。倍精度は仮数部52ビット・指数部11ビットで精度が高い |
| BCD（2進化10進） | 10進数の1桁を4ビットの2進数で表す方式（例：39 → 0011 1001） |
| パック10進数 | 1バイトに10進数2桁を詰め、最後の4ビットに符号を入れる形式。**ゾーン10進数** は1バイトに1桁 |
| アンダーフロー | 計算結果の絶対値が小さすぎて、表せる最小値より0に近くなること |
| 部分集合 | 集合Aのすべての要素が集合Bに含まれるとき、AはBの部分集合（A⊂B） |
| 命題論理 | 真か偽が決まる文（命題）を、論理演算で組み合わせて扱う論理 |
| 否定論理和（NOR）・否定論理積（NAND） | ORの結果を反転したもの・ANDの結果を反転したもの |
| 論理関数 | 論理変数を入力とし、0か1を出力する関数 |
| 分配則 | A・(B＋C) ＝ A・B＋A・C のように、演算を分配できる法則 |

### 応用数学（確率・統計）

| 用語 | 意味 |
|---|---|
| 加法定理 | P(A∪B) ＝ P(A)＋P(B)−P(A∩B)。同時に起こらないなら P(A)＋P(B) |
| 乗法定理 | P(A∩B) ＝ P(A)×P(B｜A)。独立なら P(A)×P(B) |
| 同時確率・条件付き確率 | AとBが両方起こる確率 ／ Bが起きたという条件のもとでAが起こる確率 P(A｜B) |
| ポアソン分布 | 一定時間に、まれな事象が何回起こるかの分布（窓口への到着数など） |
| ベルヌーイ分布・二項分布 | 成功か失敗かの1回の試行の分布 ／ それをn回繰り返したときの成功回数の分布 |
| 指数分布 | 次の事象が起こるまでの時間の分布（到着間隔、サービス時間） |
| カイ二乗分布 | 正規分布に従う値の2乗和の分布。適合度や独立性の検定に使う |
| 確率密度 | 連続的な値の確率の「濃さ」。区間で積分すると確率になる |
| 歪度（わいど）・尖度（せんど） | 分布の左右の偏り ／ 分布のとがり具合 |
| 相関と因果・擬似相関 | 相関があっても因果関係があるとは限らない。第3の要因によって見かけ上相関が出るのが擬似相関 |
| 説明変数・目的変数 | 予測に使う変数（原因側） ／ 予測したい変数（結果側） |
| 重回帰分析・ロジスティック回帰分析 | 複数の説明変数で予測する回帰 ／ 「買う・買わない」のような2値の確率を予測する回帰 |
| 尺度 | **名義尺度**（区別だけ：性別）、**順序尺度**（順位）、**間隔尺度**（差に意味：気温）、**比例尺度**（比に意味：重さ） |
| 点推定・区間推定 | 母集団の値を1つの値で推定 ／ 「95%の確率でこの範囲」と幅で推定 |
| 尤度（ゆうど）・最尤推定 | あるパラメータのもとで観測データが得られるもっともらしさ ／ 尤度が最大になるパラメータを推定値とする方法 |
| 仮説検定 | 「差がない」という **帰無仮説** を立て、データから起こる確率（**p値**）が **有意水準**（5%など）より小さければ帰無仮説を棄却し、**対立仮説** を採用する |
| 第1種の誤り・第2種の誤り | 正しい帰無仮説を誤って棄却する（あわてんぼう） ／ 誤った帰無仮説を棄却しない（ぼんやり） |
| 検出力 | 対立仮説が正しいときに、正しく帰無仮説を棄却できる確率（1−第2種の誤りの確率） |
| t検定・z検定・カイ二乗検定 | 平均値の差の検定（標本が少ない／母分散が既知） ／ 度数分布の適合度・独立性の検定 |

### 応用数学（数値計算・グラフ理論・待ち行列・最適化）

| 用語 | 意味 |
|---|---|
| ベクトル・行列・テンソル | 数を1列に並べたもの ／ 縦横の表に並べたもの ／ さらに多次元に拡張したもの。AIの計算の基本 |
| 単位行列・逆行列・転置行列 | 対角が1で他が0の行列 ／ 掛けると単位行列になる行列 ／ 行と列を入れ替えた行列 |
| 固有値・固有ベクトル | 行列を掛けても向きが変わらないベクトルと、その伸び縮みの倍率。主成分分析で使う |
| 掃出法 | 連立一次方程式を、行の操作で順に変数を消去して解く方法（ガウスの消去法） |
| 等差数列・等比数列・フィボナッチ数列 | 一定の差で増える列 ／ 一定の比で増える列 ／ 前の2項の和が次の項になる列（1,1,2,3,5,8…） |
| 対数 | 2<sup>x</sup>＝8 なら x＝log<sub>2</sub>8＝3。二分探索の回数や情報量の計算で使う |
| 微分・積分 | 変化の割合（傾き）を求める ／ 面積（累積量）を求める |
| ニュートン法 | 接線とx軸の交点を次の近似値にして、方程式の解に速く収束させる近似解法 |
| 数値積分・シンプソン法 | 面積を細かい図形の和で近似計算する ／ 曲線を放物線で近似して積分する方法 |
| 絶対誤差・相対誤差 | 真の値との差 ／ その差を真の値で割った割合 |
| 無向グラフ・完全グラフ・重みつきグラフ | 辺に向きがない ／ すべての頂点どうしが辺で結ばれている ／ 辺に距離などの値がある |
| 閉路・正則グラフ | 出発点に戻る経路 ／ すべての頂点の辺の数が同じグラフ |
| 平均サービス率 | 窓口が単位時間に処理できる平均件数（μ）。利用率 ρ ＝ 到着率 λ ÷ μ |
| 巡回セールスマン問題 | すべての都市を1回ずつ回って戻る最短経路を求める組合せ最適化問題。都市が増えると計算量が爆発的に増える |
| 連続最適化問題 | 変数が連続値をとる最適化問題（線形計画法など） |
| ベルマンフォード法 | 負の重みの辺があっても使える最短経路アルゴリズム |

### 情報に関する理論・AI

| 用語 | 意味 |
|---|---|
| 文字コード | **ASCII**（英数字の7ビットコード）、**JISコード**、**シフトJIS**（Windowsで使われた日本語コード）、**EUC**（UNIXの日本語コード）、**Unicode**（世界の文字を1つの体系で扱う。符号化方式にUTF-8など） |
| プッシュダウンオートマトン | スタックを持つオートマトン。かっこの対応など、有限オートマトンでは扱えない言語を受理できる |
| 文脈自由文法 | BNFで書ける文法。プログラム言語の構文の定義に使う |
| 停止問題 | 任意のプログラムが停止するかどうかを判定するプログラムは作れない、という計算理論の結果 |
| 時間計算量・領域計算量 | 処理時間の増え方 ／ 必要なメモリ量の増え方 |
| P問題・NP問題・NP完全問題 | 多項式時間で解ける問題 ／ 答えが与えられれば多項式時間で確かめられる問題 ／ NPの中で最も難しい問題群（巡回セールスマン問題など） |
| エキスパートシステム | 専門家の知識を **知識ベース** に蓄え、**推論エンジン** で結論を導くAI |
| 半教師あり学習 | 少量の正解付きデータと大量の正解なしデータを組み合わせて学習する |
| 自己教師あり学習 | データ自身から正解を作って学習する（文章の一部を隠して当てさせるなど）。大規模言語モデルの事前学習で使う |
| 線形回帰・決定木・ランダムフォレスト | 直線で予測 ／ 条件分岐の木で分類 ／ 多数の決定木の多数決で精度を高める |
| サポートベクトルマシン（SVM） | 2つのクラスの境界との距離（マージン）が最大になるように分類する手法 |
| Q学習・方策勾配法・価値反復法 | 強化学習の手法。行動の価値（Q値）を学習する ／ 方策を直接改善する ／ 状態の価値を繰り返し更新する |
| ハイパーパラメータ | 学習率や層の数など、学習の前に人が決める設定値。**グリッドサーチ**（全組合せを試す）、**ランダムサーチ** で調整する |
| 学習率 | 1回の学習で重みをどれだけ修正するかの大きさ |
| 汎化性能・汎化誤差・訓練誤差 | 未知のデータに対する性能 ／ 未知のデータでの誤差 ／ 学習データでの誤差 |
| バイアスとバリアンスのトレードオフ | 単純なモデルは偏り（バイアス）が大きく、複雑なモデルはばらつき（バリアンス）が大きい。両方は同時に小さくしにくい |
| 正則化 | 重みが大きくなりすぎないように罰則を加えて、過学習を防ぐ |
| ドロップアウト | 学習中にニューロンの一部をランダムに無効にして、過学習を防ぐ |
| アンサンブル学習 | 複数のモデルを組み合わせて精度を上げる（バギング、ブースティング） |
| ホールドアウト検証 | データを学習用と評価用に1回だけ分けて評価する方法 |
| PR曲線 | 横軸に再現率、縦軸に適合率をとった曲線。陽性が少ないデータの評価に向く |
| AIのロバスト性 | ノイズや想定外の入力があっても性能が落ちにくい性質 |
| 多層パーセプトロン | 入力層・隠れ層・出力層を持つ基本的なニューラルネットワーク |
| 勾配消失問題 | 層が深いと、誤差逆伝播で修正量（勾配）が小さくなり、入力側の層が学習されなくなる問題 |
| CNN（畳み込みニューラルネットワーク） | 画像の局所的な特徴を「畳み込み」で抽出する。画像認識に使う |
| LSTM | 長い時系列の情報を記憶できる再帰型ニューラルネットワーク。音声・文章の処理に使う |
| Transformer・自己注意機構 | 文中の各単語が他のどの単語に注目すべきかを計算する仕組み（Self-Attention）を中心にしたモデル。大規模言語モデルの基盤 |
| 事前学習・ファインチューニング | 大量のデータで汎用的に学習しておく ／ それを特定の目的のデータで追加学習して調整する |
| バッチ学習・ミニバッチ学習・オンライン学習 | 全データでまとめて学習 ／ 小分けにして学習 ／ データが届くたびに1件ずつ学習 |
| 生成モデル・オートエンコーダ・拡散モデル | データを新しく生成するモデル ／ 入力を圧縮して復元するネットワーク ／ ノイズから少しずつ画像を復元して生成するモデル |
| 深層強化学習 | 強化学習にディープラーニングを組み合わせたもの（囲碁AIなど） |
| 基盤モデル | 大量のデータで事前学習され、様々な用途に転用できる大規模なモデル |
| アラインメント・RLHF | AIの出力を人間の意図や価値観に沿わせること ／ 人の評価（フィードバック）を報酬にした強化学習でそれを行う手法 |
| ゼロショット学習・フューショット学習 | 例を示さずに課題を解かせる ／ 少数の例を示して解かせる |
| インストラクションチューニング | 「指示と望ましい応答」の組でモデルを追加学習し、指示に従いやすくする |
| プロンプトエンジニアリング | 生成AIから望む出力を得るために、指示文（プロンプト）を工夫する技術 |
| 手続型・関数型・論理型・オブジェクト指向言語 | 手順を順に書く（C） ／ 関数の組合せで書く（Haskell） ／ 事実と規則から推論させる（Prolog） ／ オブジェクトで組み立てる（Java） |
| 中間言語 | ソースコードと機械語の中間の表現（Javaのバイトコードなど） |

### 通信に関する理論

| 用語 | 意味 |
|---|---|
| 半二重・全二重 | 送信と受信を交互に行う ／ 同時に行う |
| 変調・QAM・モデム | デジタル信号を電波などに乗せること ／ 振幅と位相の両方を変えて多くのビットを送る方式 ／ 変調・復調する装置 |
| 多重化（FDM・TDM・CDM・WDM） | 1本の回線を周波数で分ける ／ 時間で分ける ／ 符号で分ける ／ 光の波長で分ける |
| 同期方式 | **調歩同期**（文字ごとにスタートビットとストップビットを付ける）、**SYN同期**（同期用文字を先頭に付ける）、**フラグ同期**（フラグパターンでフレームを区切る：HDLC） |
| 符号理論 | 誤り検出・訂正（通信路符号化）やデータ圧縮（情報源符号化）の理論 |

| センサー（光学・イメージ・赤外線・磁気・地磁気・圧力・湿度など） | 光の量、画像、熱、磁界（ホール素子で検出）、方位、圧力、湿度を電気信号に変える部品 |
| ToFセンサー | 光を発射して反射して戻るまでの時間から距離を測る |
| IMU（慣性計測装置） | 加速度センサーとジャイロセンサーを組み合わせ、姿勢や移動を計測する |
| モーター | **ステッピングモーター**（パルス数で角度を正確に制御）、**DCサーボモーター**（フィードバックで位置を制御）、**ブラシレスDCモーター**（ブラシがなく長寿命） |
| ソレノイド・油圧／空気圧シリンダ | 電磁石で直線運動を作る ／ 油や空気の圧力で直線運動を作るアクチュエータ |
| 測位 | **基地局測位**、**無線LANアクセスポイント測位**、**RTK測位**（基準局の補正情報で数cm精度にするGNSS測位） |

## 2. アルゴリズムとプログラミング

|---|---|

| 流れ図記号 | 端子（開始・終了）、定義済み処理（別に定義した処理の呼出し）、ループ端（繰返しの始めと終わり） |

| 静的変数・自動変数 | プログラム実行中ずっと存在する変数 ／ 関数の呼出しごとに作られ、終われば消える変数 |

| 共通言語基盤（CLI） | .NET で、異なる言語から作った中間コードを共通の環境で実行する仕組み |
| XMLの関連技術 | **DTD・XML Schema**（文書の構造の定義）、**DOM**（文書を木構造で読み込んで操作するAPI）、**SAX**（先頭から順にイベントとして読むAPI）、**XSL**（XMLの変換・表示形式の指定）、**SGML**（XML・HTMLの元になった言語） |
| SOAP | XMLでメッセージをやり取りするWebサービスのプロトコル |
| CSS | HTMLの見た目（色・配置など）を指定する言語 |
| UMLのその他の図 | **オブジェクト図**（ある時点のインスタンスの関係）、**コンポーネント図**、**パッケージ図**、**配置図**（ハードウェアとソフトの配置）、**タイミング図**（時間軸での状態変化）、**相互作用概要図** |

## 3. コンピュータ構成要素

### プロセッサ

| 用語 | 意味 |
|---|---|
| DSP | 音声・画像などの信号処理に特化したプロセッサ（積和演算が速い） |
| FPU | 浮動小数点演算を専門に行う装置 |
| AIチップ・TPU | AIの計算（行列演算）に特化したプロセッサ。TPUはGoogleが開発したもの |

| 積和演算器 | A×B＋C をまとめて計算する回路。DSP・AIで多用 |
| 組合せ回路・順序回路 | 出力が現在の入力だけで決まる回路 ／ 過去の状態（記憶）にも依存する回路（フリップフロップを含む） |
| 割込みの種類 | **SVC割込み**（プログラムがOSの機能を呼び出す）、**プログラム割込み**（ゼロ除算・オーバーフローなど）、**マシンチェック割込み**（ハードウェアの故障）、**入出力割込み**、**タイマ割込み** |
| マスク可能割込み・NMI | 禁止（マスク）できる割込み ／ 禁止できない最優先の割込み（電源異常など） |
| 水平型・垂直型マイクロコード | 1命令で多数の制御信号を並列に指定する ／ 命令を符号化して短くした形式 |
| ベクトル処理 | 配列などの多数のデータに同じ演算を一括で行う方式（スーパーコンピュータ） |
| マルチスレッディング | 1つのコアで複数のスレッドを同時に実行し、演算器の空きを減らす（ハイパースレッディング） |
| SISD・MISD・SIMD・MIMD | 命令とデータの流れが単一か複数かによる並列計算機の分類（フリンの分類） |
| SMP（対称型マルチプロセッシング） | すべてのプロセッサが主記憶を共有し、対等に処理を分担する |
| 相互結合網（トーラス・ハイパーキューブ） | 多数のプロセッサをつなぐ網の形。ドーナツ状、n次元の立方体状 |

### メモリ・バス・入出力

| 用語 | 意味 |
|---|---|
| マスクROM・EPROM・EEPROM | 製造時に内容を書き込む ／ 紫外線で消去できる ／ 電気的に消去・書換えできるROM |
| FeRAM | 強誘電体を使った不揮発メモリ。高速で書換え回数が多い |
| SDRAM・DDR SDRAM | クロックに同期して動くDRAM ／ クロックの立ち上がりと立ち下がりの両方でデータを転送し高速化したもの（DDR4、DDR5…） |
| DIMM・SO-DIMM | デスクトップ用・ノートPC用のメモリモジュールの形状 |
| ビッグエンディアン・リトルエンディアン | 複数バイトのデータを、上位バイトから ／ 下位バイトから メモリに格納する方式 |
| 連想メモリ | アドレスではなく内容で検索できるメモリ（TLBなどで使う） |
| 命令キャッシュ・データキャッシュ | 命令用とデータ用にキャッシュを分ける（同時にアクセスできる） |
| ディスクキャッシュ | 磁気ディスクと主記憶の間に置くキャッシュ |
| 光ディスク | CD・DVD・ブルーレイ。読出し専用型・追記型（-R）・書換型（-RW、-RAM） |
| ストリーマ | バックアップ用の磁気テープ装置 |
| バスの種類 | **アドレスバス**（アドレスを送る）、**データバス**（データを送る）、**コントロールバス**（制御信号を送る）。アドレスバスがnビットなら 2<sup>n</sup> 番地を指定できる |
| バスアービタ・バスマスター | バスの使用権を調停する装置 ／ バスの使用権を得てデータ転送を制御する装置 |
| ポーリング方式 | CPUが入出力装置の状態を定期的に問い合わせる方式（割込み方式と対比） |
| インタフェース | **Thunderbolt**（映像・データ・給電の高速シリアル）、**DisplayPort**（映像）、**シリアルATA**（ストレージ接続）、**RS-232C**（旧来のシリアル）、**IrDA**（赤外線）、**Wi-SUN**（スマートメーター向け無線）、**UART**（調歩同期のシリアル通信回路） |
| デイジーチェーン接続 | 機器を数珠つなぎに接続する方式。終端には **ターミネーター** を付ける（SCSI） |
| Nキーロールオーバー | 同時に多数のキーを押しても、すべて正しく認識されるキーボードの性能 |
| 入力装置 | **OCR**（文字読取）、**OMR**（マークシート読取）、**ハプティックデバイス**（触覚を返す）、**アイトラッキング**（視線を測る） |
| TFT液晶・STN液晶 | 画素ごとにトランジスタを持つ高画質な液晶 ／ 単純な構造の低価格な液晶 |
| 磁気ディスクの用語 | **シリンダ**（同じ位置にあるトラックの集まり）、**セクター**（トラックを区切った最小単位）、**サーチタイム**（回転待ち時間） |
| ブロック化因数・IBG | 1ブロックに入れる論理レコードの数 ／ 磁気テープのブロック間の隙間 |
| デフラグメンテーション | ディスク上で断片化したファイルを連続した領域に並べ直すこと |
| MAID | アクセスのないディスクを停止して省電力化するディスクアレイ |

## 4. システム構成要素

| 用語 | 意味 |
|---|---|
| 水平機能分散・水平負荷分散・垂直機能分散 | 対等なコンピュータで機能を分担 ／ 同じ機能を複数台で分担 ／ 階層的に役割を分ける（クライアントとサーバ） |
| TCO（総保有コスト） | 導入費用だけでなく、運用・保守・教育などを含めたシステムの総費用 |
| タンデム結合 | 前段と後段のプロセッサで処理を分担し、直列に流す |
| バックアップサイト | 災害時の代替拠点。**ホットサイト**（すぐ切替え可能）、**ウォームサイト**（機器はあるがデータ復元が必要）、**コールドサイト**（場所と設備だけ） |
| シェアードエブリシング・シェアードナッシング | 複数のサーバがディスクを共有する ／ 各サーバが自分のディスクだけを使う（拡張性が高い） |
| サーバコンソリデーション | 複数のサーバを仮想化などで少数のサーバに集約すること |
| RPC | 別のコンピュータ上の手続を、ローカルの手続のように呼び出す仕組み |
| RAID 2・3・4・10 | ハミング符号で冗長化 ／ ビット・バイト単位でパリティ専用ディスク ／ ブロック単位でパリティ専用ディスク ／ RAID 1＋0 |
| FC-SAN・IP-SAN | ファイバチャネルで構成するSAN ／ IPネットワーク（iSCSI）で構成するSAN |
| 信頼性ブロック図 | 装置の直列・並列のつながりを図にして稼働率を計算するための図 |
| フォールトマスキング | 故障が起きても、多数決などで誤りを外に見せない技術 |
| 無停止コンピュータ | すべての部品を多重化して、故障しても停止しないコンピュータ |
| SPECint・SPECfp・ギブソンミックス | 整数演算・浮動小数点演算の性能のベンチマーク ／ 命令の出現頻度で平均命令実行時間を求める方法 |
| サイジング | 必要な処理能力に見合うハードウェアの規模を見積もること |
| プロビジョニング | 必要に応じてサーバなどの資源を割り当て、すぐ使える状態にすること |
