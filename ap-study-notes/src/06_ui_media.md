## 1. ヒューマンインタフェース

### GUI 部品の使い分け

| 部品 | 用途 |
|---|---|
| ラジオボタン | 複数の選択肢から **1つだけ** 選ばせる |
| チェックボックス | 複数の選択肢から **いくつでも** 選ばせる（ON/OFF） |
| プルダウンメニュー（リストボックス） | 選択肢が多いときに、一覧から選ばせる。画面を節約できる |
| テキストボックス | 自由に文字を入力させる |
| スライダー | 連続した値（音量など）を直感的に指定させる |

### 画面設計・帳票設計の原則

- 入力の順序は、元になる伝票や業務の流れに合わせる。
- 関連する項目はまとめて配置し、画面間で操作方法や配色を **統一** する。
- 入力ミスを防ぐため、コード入力には選択式やチェックディジットを使い、エラーメッセージは何をどう直せばよいかを具体的に示す。
- 頻繁に使う機能にはショートカットキーを用意し、熟練者の操作を効率化する。

### ユーザビリティとアクセシビリティ

- **ユーザビリティ**：特定の利用者が、特定の目的を、有効に・効率よく・満足して達成できる度合い（使いやすさ）。
- **ヒューリスティック評価**：専門家が経験則（ガイドライン）に照らしてUIの問題点を洗い出す評価手法。
- **ユーザビリティテスト**：実際の利用者に操作してもらい、観察して問題点を見つける手法。**思考発話法**（考えていることを声に出しながら操作してもらう）がよく使われる。
- **アクセシビリティ**：高齢者や障害者を含め、**誰もが** 情報やサービスを利用できること。Webでは **JIS X 8341** や **WCAG** というガイドラインがある（画像に代替テキストを付ける、色だけで情報を伝えない、など）。
- **ユニバーサルデザイン**：年齢・能力・国籍などにかかわらず、**最初からすべての人が使いやすい** ように設計する考え方。
- **UX（ユーザエクスペリエンス）**：製品やサービスを使う前・中・後を通じて利用者が得る体験全体。
- **ペルソナ**：典型的な利用者像を、名前・年齢・行動などを具体的に設定して描いた架空の人物。設計の判断基準にする。

## 2. マルチメディア

### 画像のデジタル表現

- **画素（ピクセル）**：画像を構成する小さな点。画素の数が多いほど細かい画像になる（**解像度**）。
- **色深度**：1画素の色を何ビットで表すか。24ビット（R・G・B 各8ビット）なら約1,677万色（**フルカラー**）。
- **光の三原色 RGB**：画面表示で使う。混ぜるほど明るくなり、全部混ぜると白（**加法混色**）。
- **色の三原色 CMY（＋K）**：印刷で使う。混ぜるほど暗くなる（**減法混色**）。K は黒。

:::calc 画像のデータ量
横 1,920 × 縦 1,080 画素、24ビットフルカラーの画像1枚のデータ量は？
画素数 ＝ 1,920 × 1,080 ＝ 2,073,600 画素。1画素 ＝ 24ビット ＝ 3バイト。
データ量 ＝ 2,073,600 × 3 ＝ 6,220,800 バイト ≒ **約6.2Mバイト**
:::

:::calc 音声のデータ量
サンプリング周波数 44.1kHz、量子化ビット数 16ビット、ステレオ（2チャネル）で1分間録音したデータ量は？
1秒間 ＝ 44,100 回 × 16ビット × 2チャネル ＝ 1,411,200 ビット ＝ 176,400 バイト
1分間 ＝ 176,400 × 60 ＝ 10,584,000 バイト ≒ **約10.6Mバイト**
:::

### 圧縮方式

| 分類 | 意味 | 例 |
|---|---|---|
| **可逆圧縮** | 圧縮したデータを **完全に元に戻せる** | ZIP、PNG、GIF、FLAC |
| **非可逆圧縮** | 人が気づきにくい情報を捨てて高い圧縮率を実現。完全には戻せない | JPEG（静止画）、MPEG（動画）、MP3・AAC（音声） |

- **MPEG** は、前後のフレーム（コマ）との **差分** だけを記録することで動画を大きく圧縮する。H.264、H.265 などの規格がある。
- **ビットレート**：1秒あたりのデータ量（bps）。動画のデータ量 ＝ ビットレート × 時間 ÷ 8 でバイトに換算。

### VR・AR・その他の技術

| 技術 | 内容 |
|---|---|
| **VR**（仮想現実） | コンピュータが作った仮想空間に入り込んだような体験をさせる |
| **AR**（拡張現実） | 現実の映像に、デジタル情報を **重ねて** 表示する |
| **MR**（複合現実） | 現実と仮想を融合し、仮想物体に触れるなど相互作用できる |
| **メタバース** | インターネット上の3次元仮想空間で、アバターを通じて交流・経済活動を行う |
| **CG のレンダリング** | 3次元のデータから画像を生成すること。**テクスチャマッピング**（表面に模様を貼る）、**レイトレーシング**（光線を追跡して反射・屈折を計算）など |
| **モーションキャプチャ** | 人の動きをセンサーで計測し、CGキャラクターに反映する |

## 3. 過去問（令和2〜6年度）で問われた発展テーマ

- **パンくずリスト**：Web サイトで、トップページから現在のページまでの道筋（階層）を「ホーム ＞ 製品 ＞ ノートPC」のように表示するもの。利用者が現在位置を把握し、上の階層に戻りやすくなる。
- **アイコンの規格（JIS X 9303）**：機能アイコンなどのシンボルの設計原則を定めた規格。見ただけで機能がわかるよう、一貫したデザインにする。
- **アウトラインフォント**：文字の形を **輪郭線（線や曲線の式）** で表すフォント。拡大・縮小しても滑らかに表示できる。**ビットマップフォント** は点の集まりで表すため、拡大するとギザギザになる。
- **レイトレーシング**：視点から画面の各画素を通る光線（レイ）を逆にたどり、物体での反射・屈折・影を計算して、写実的な画像を作る。
- **レンダリング**：3次元の形状データなどから、画面に表示する2次元の画像を生成すること。
- **テクスチャマッピング**：立体の表面に画像（模様や質感）を貼り付ける手法。
- **UXデザイン**：利用者がシステムを使う前・使っている間・使った後の体験全体を良くすることを目的に、利用者の行動や感情を調査して設計する。
- **画面の画素とメモリ**：1画素を1ビットで表す 640 × 480 画素の白黒画面なら、必要なメモリは 640 × 480 ÷ 8 ＝ 38,400 バイト。何ビット目がどの画素に対応するかは、問題文の割当て方式に従う。

:::sum
- ラジオボタンは1つだけ、チェックボックスは複数選択。アクセシビリティ＝誰もが利用可能。
- 画像のデータ量 ＝ 画素数 × 色深度。音声 ＝ サンプリング周波数 × 量子化ビット数 × チャネル数 × 秒。
- 標本化定理：最高周波数の2倍以上でサンプリング。
- 可逆（ZIP・PNG）と非可逆（JPEG・MPEG・MP3）。AR は現実に重ねる、VR は仮想空間に入る。
:::
