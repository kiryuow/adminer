## 7. ユーザーインタフェース

| 用語 | 意味 |
|---|---|
| アフォーダンス・シグニファイア | 物の形が使い方を示唆する性質（取っ手は引けそう） ／ 使い方を伝える手がかり（「押す」の表示、ボタンの影） |
| チャンク | 人が一度に覚えられる情報のかたまり。電話番号を区切って表示するなど |
| NUI・VUI・マルチモーダルインタフェース | 身振りや音声など自然な動作で操作するUI ／ 音声で操作するUI ／ 音声・タッチ・視線など複数の手段を組み合わせるUI |
| マルチタッチ操作 | タップ、スワイプ（なぞる）、フリック（はじく）、ピンチ（2本指で拡大縮小）、ロングプレス |
| OOUI・タスク指向UI | 先に対象（オブジェクト）を選び、次に操作を選ぶUI ／ 先にやりたいこと（タスク）を選ぶUI |
| GUI部品 | トグルボタン（ON/OFF切替え）、ポップアップメニュー、アコーディオン（見出しをクリックで開閉）、ツールチップ（マウスを重ねると出る説明）、カルーセル（横に流れるスライド） |
| セマンティックWeb | Webの情報に意味（メタデータ）を付けて、コンピュータが内容を理解・処理できるようにする構想 |
| フォークソノミー | 利用者が自由にタグを付けて情報を分類する方法 |
| UXハニカム | 役に立つ・使いやすい・望ましい・見つけやすい・アクセスしやすい・信頼できる・価値がある、の7つのUX要素 |
| エモーショナルデザイン | 使う人の感情（楽しい、心地よい）に訴えるデザイン |
| タイポグラフィ・ムードボード | 文字の書体や配置のデザイン ／ デザインの雰囲気を伝えるため写真や色見本を集めたボード |
| ストーリーボード・ワイヤーフレーム | 利用者の体験の流れを絵コンテで表したもの ／ 画面の要素の配置を線で示した設計図 |
| 入力チェック | **ニューメリックチェック**（数値か）、**フォーマットチェック**（形式）、**リミットチェック**（範囲）、**組合せチェック**（項目間の矛盾）、**照合チェック**（マスタと照合）、**バランスチェック**（貸借の一致）、**チェックキャラクター**（チェックディジット） |
| コード設計 | **順番コード**（連番）、**区分コード**（範囲で分類）、**桁別コード**（桁ごとに意味）、**表意コード**（見て意味がわかる：L, M, S）、**合成コード**（組合せ） |
| レスポンシブWebデザイン・メディアクエリ | 画面の大きさに応じてレイアウトを自動で変える設計 ／ そのためにCSSで画面幅などの条件を指定する機能 |
| モバイルファースト・プログレッシブエンハンスメント | スマホ向けを先に設計する ／ 基本機能をすべての環境で動かし、高機能な環境では機能を追加する |
| クロスブラウザ | 異なるWebブラウザでも同じように表示・動作すること |
| UXライティング | ボタンやエラーメッセージなど、UI上の短い文章を利用者にわかりやすく書くこと |
| 人間中心設計（JIS Z 8530） | 利用状況の理解と明示 → ユーザー要求事項の明示 → 設計解の作成 → 評価、を繰り返す設計プロセス |
| インクルーシブデザイン | 障害者や高齢者など、これまで排除されがちだった人を設計の初期から巻き込んでデザインする |
| エルゴノミクス・ピクトグラム | 人間工学（体に無理のない設計） ／ 非常口マークのような絵文字の案内表示 |
| WAI | Webのアクセシビリティを推進するW3Cの取組み。WCAGを策定 |
| ユーザビリティ評価手法 | **認知的ウォークスルー**（専門家が初心者になったつもりで操作手順を検証）、**回顧法**（操作後に感想を聞く）、**NEM**（初心者と熟練者の操作時間の比で問題箇所を探す）、**アイトラッキング分析**、**A/Bテスト**（2つの案を利用者に出し分けて効果を比べる） |

## 8. 情報メディア

| 用語 | 意味 |
|---|---|
| ハイパーメディア | 文字・画像・音声などをリンクで相互に結び付けたもの |
| ストリーミング | 音声や動画をダウンロードしながら同時に再生する方式 |
| コンテナフォーマット | 映像・音声・字幕などをまとめて1つのファイルに格納する形式（MP4、MOVなど） |
| 音声形式 | **WAV・AIFF**（非圧縮）、**MIDI**（音そのものではなく、演奏情報を記録） |
| 画像形式 | **BMP**（非圧縮）、**TIFF**（タグで多様な形式を表せる）、**HEIF**（高圧縮）、**Exif**（デジタルカメラの撮影情報を付加する形式） |
| ラスターデータ・ベクターデータ | 画素の集まりで表す画像 ／ 線や図形の式で表す画像（拡大しても劣化しない） |
| HEVC（H.265） | H.264の約2倍の圧縮効率を持つ動画圧縮方式。4K/8K放送で使う |
| インターレース・プログレッシブ | 1画面を奇数行と偶数行に分けて交互に表示 ／ 全行を順に表示 |
| ノンリニア編集 | 動画をデジタルで扱い、任意の場面に直接アクセスして編集する方法 |
| MMR | ファクシミリで使われる白黒画像の圧縮方式 |
| YUV | 輝度（Y）と色差（U・V）で色を表す方式。人の目は色より明るさに敏感なので、色差を間引いて（YUV420など）データ量を減らす |
| dpi・ppi | 1インチあたりの点の数（印刷） ／ 1インチあたりの画素数（画面） |
| アンチエイリアシング | 斜めの線のギザギザを、中間色で滑らかに見せる処理 |
| ディザリング | 少ない色数で、点の配置によって中間色を表現する処理 |
| ガンマ補正 | 機器による明るさの表示特性の違いを補正すること |
| シェーディング | 光の当たり方に応じて物体の表面に陰影を付けること（グローシェーディング、フォンシェーディング） |
| キープレート | 印刷のCMYKのK（黒）のこと |

## 9. データベース

| 用語 | 意味 |
|---|---|
| 階層型・網型DB | データを木構造で表す ／ 網目状の親子関係で表す（構造型データベース） |
| OODB・XMLデータベース | オブジェクトをそのまま格納するDB ／ XML文書をそのまま格納・検索するDB |
| 列指向DB・インメモリDB | 列単位でデータを格納し集計が速い ／ データを主記憶上に置いて高速に処理するDB |
| 主なNoSQL製品 | **MongoDB**（ドキュメント型）、**Redis**（キーバリュー型、インメモリ）、**Cassandra**（列指向型）、**Neo4j**（グラフ型） |
| データディクショナリ（データ辞書） | DBの表・列の名前、意味、型などの定義情報をまとめたもの |
| 論理データモデル・物理データモデル | DBMSに依存しない表の構造 ／ 特定のDBMSでの実装（索引、格納場所など）まで決めたもの |
| サロゲートキー | 業務上の意味を持たず、行を識別するためだけに付ける人工的なキー（連番など） |
| 完全関数従属 | 主キー全体には従属するが、その一部には従属しないこと（第2正規形の条件） |
| 非正規化 | 性能向上のため、あえて正規化を崩して表を結合した形で持つこと |
| 副次索引・転置ファイル | 主キー以外の列で検索するための索引 ／ 値から行の位置を逆引きするファイル |
| 埋込みSQL | プログラム言語の中にSQL文を書き込んで使う方法 |
| 検査制約（CHECK） | 列の値が満たすべき条件を定義する制約 |
| 相関名 | FROM句で表に付ける別名（FROM 社員 E の E） |
| インデックスの種類 | **B-tree**（範囲検索に強い）、**ハッシュ**（一致検索に強い）、**ビットマップ**（値の種類が少ない列向き）、**ユニーク**（重複不可）、**クラスタ化**（データの格納順を索引順にする）、**カバリング**（索引だけで問合せに答えられる） |
| シャドウページ法 | 更新するページのコピーを作って更新し、コミット時に切り替えることで障害回復する方法 |
| ウォームスタート・コールドスタート | 主記憶の内容を使って障害直前から再開する ／ 初期状態から立ち上げ直す |
| ダンプ・リストア | DBの内容をファイルに丸ごと書き出す（バックアップ） ／ それを書き戻す |
| ETL・ELT | 抽出 → 変換 → 書込み の順でデータを統合する ／ 先に書き込んでから変換する（クラウドのデータ基盤で多い） |
| データクレンジング | 表記ゆれ、重複、誤りなどを修正してデータの品質を高めること |
| 分散DBの透過性 | 利用者がデータの格納場所などを意識せずに使えること（位置透過性など） |
| 半構造化データ | JSON・XMLのように、表ほど厳密ではないが一定の構造を持つデータ |
| ストリーミングデータ | センサーなどから絶え間なく流れてくるデータ。到着するたびに処理する |
| 分散ファイルシステム・クエリエンジン | HDFS、Cephなど多数のサーバでファイルを分散保管する仕組み ／ Hive、Presto など大量データにSQLで問い合わせる仕組み |

## 10. ネットワーク

| 用語 | 意味 |
|---|---|
| MDF・IDF | 建物の主配線盤 ／ 各フロアの中間配線盤 |
| 回線交換・パケット交換 | 通信中は回線を専有する（電話） ／ データを小さなパケットに分け、回線を共有する |
| 伝送媒体 | **より対線**（LANケーブル）、**同軸ケーブル**、**光ファイバ**（高速・長距離・電磁ノイズに強い） |
| インフラストラクチャモード・アドホックモード | アクセスポイント経由で通信する無線LAN ／ 端末どうしが直接通信する |
| 隠れ端末問題・さらし端末問題 | 互いの電波が届かない端末が同時に送信して衝突する（RTS/CTSで対策） ／ 本来送信できるのに、他の通信を検知して送信を控えてしまう |
| VoIP・IP電話 | 音声をIPパケットにして送る技術 ／ それを使った電話サービス |
| 呼量・アーラン・呼損率 | 電話回線の使用量（1回線を1時間使い続けると1アーラン） ／ 回線が埋まっていてつながらない確率。アーランB式で計算 |
| アドレスクラス | IPv4の旧来の区分。クラスA（/8）・B（/16）・C（/24）。現在はCIDRが主流 |
| オーバーレイネットワーク | 既存の物理ネットワークの上に、仮想的なネットワークを重ねて構築する |
| TLD | トップレベルドメイン（.jp、.com など） |
| ネットワークトポロジー | スター型、バス型、リング型、ツリー型、メッシュ型 |
| TDMA | 時間を区切って複数の利用者が交互に使う多元接続方式 |
| リバースプロキシ | 外部からの要求をサーバの手前で受けて中継する。負荷分散、TLS終端、キャッシュ、WAFなどに使う |
| フロー制御 | 受信側の処理が追いつくように送信量を調整すること（TCPのウィンドウ制御） |
| トークンパッシング | 送信権（トークン）を持つ端末だけが送信できる方式 |
| RARP | MACアドレスからIPアドレスを求める（ARPの逆） |
| PPP・PPPoE・IPoE | 2点間の接続プロトコル ／ それをイーサネット上で使う（フレッツの旧来方式） ／ PPPを使わずIPを直接使う接続方式（混雑しにくい） |
| IEEE 802.1Q | VLANのタグ（VLAN番号）をフレームに付ける規格 |
| イーサネット規格 | 10BASE-T・100BASE-TX・1000BASE-T・10GBASE-T（数字が速度 Mbps、Tはより対線） |
| ネットワーク管理コマンド | **ifconfig／ipconfig**（IP設定の表示）、**netstat**（接続状況）、**dig／nslookup**（DNS問合せ）、**traceroute／tracert**（経路の確認）、**tcpdump・Wireshark**（パケットの取得・解析） |
| SNMPの用語 | **MIB**（監視対象機器の管理情報のデータベース）、**マネージャ**（管理ステーション）と **エージェント**（機器側）。get（情報取得）、set（設定）、**trap**（異常を機器から通知） |
| トンネリング | あるプロトコルのパケットを別のプロトコルで包んで送ること（VPN） |
| SD-WAN・NFV | 拠点間のWANをソフトウェアで一元的に制御する ／ ルータやファイアウォールなどの機能を汎用サーバ上のソフトウェアで実現する |
| QUIC | UDPを使い、接続確立を速くした通信プロトコル。HTTP/3で使う |
| base64 | バイナリデータを英数字などの64種類の文字で表す符号化。メールの添付ファイルで使う |
| WebDAV・CGI | Webサーバ上のファイルを編集・管理するHTTPの拡張 ／ Webサーバから外部プログラムを呼び出す仕組み |
| FTPのアクティブモード・パッシブモード | データ用の接続をサーバから張る ／ クライアントから張る（ファイアウォールを通りやすい） |
| TFTP | 認証のない簡易なファイル転送（UDP）。ネットワーク機器の設定などに使う |
| 通信サービス | **FTTH**（光回線を家庭まで）、**xDSL**（電話線で高速通信）、**広域イーサネット**、**IP-VPN**（通信事業者の閉じたIP網）、**ベストエフォート**（最大速度を保証しない） |
| IPセントレックス | 構内交換機（PBX）の機能を通信事業者のネットワーク上で提供するサービス |
| 5Gの用語 | **SA方式**（5G単独）、**NSA方式**（4Gと組み合わせる）、**ネットワークスライシング**（用途ごとに仮想的にネットワークを分割）、**ローカル5G**（企業や自治体が自営で構築）、**VoLTE**（4Gでの音声通話） |
| SIM・eSIM | 契約者情報を記録したICカード ／ 端末に組み込まれ書き換え可能なSIM |
| MIMO・ビームフォーミング | 複数のアンテナで同時に送受信して高速化する ／ 電波を特定の方向に集中させる |
| フェムトセル | 屋内などをカバーする小型の携帯電話基地局 |
| テレマティクス・ローミング | 自動車と通信を組み合わせたサービス ／ 契約外の事業者の回線を使って通信すること |
| IEEE 802.11ah（Wi-Fi HaLow） | 920MHz帯を使い、遠くまで届く省電力のIoT向け無線LAN |

## 11. セキュリティ

### 脅威・攻撃

| 用語 | 意味 |
|---|---|
| 多層防御 | 入口・内部・出口などに複数の対策を重ね、1つが破られても防げるようにする |
| セキュリティバイデザイン・プライバシーバイデザイン | 企画・設計の段階からセキュリティ／プライバシー保護を組み込むこと |
| マクロウイルス | 文書ファイルのマクロ機能を悪用するウイルス |
| RAT | 感染した端末を遠隔操作するマルウェア |
| バックドア | 侵入者が再び入れるように仕掛けた裏口 |
| ポリモーフィック型・メタモーフィック型 | 感染のたびに暗号化の方法を変える ／ コードそのものを変える。パターンマッチングで検知されにくい |
| エクスプロイトコード・エクスプロイトキット | 脆弱性を突くプログラム ／ 複数の攻撃コードをまとめたツール |
| 割れ窓理論 | 小さな乱れを放置すると、大きな犯罪を招くという考え方。小さなルール違反も見逃さない |
| 防犯環境設計 | 建物や環境の設計で犯罪を起こしにくくする考え方 |
| スクリプトキディ・ボットハーダー | 他人が作ったツールで攻撃する未熟な攻撃者 ／ ボットネットを操る者 |
| ハクティビズム | 政治的・社会的な主張のためにサイバー攻撃を行うこと |
| 二重脅迫（ダブルエクストーション）・リークサイト | ランサムウェアで暗号化に加え、盗んだデータの公開も脅す ／ 盗んだデータを公開するサイト |
| RaaS | ランサムウェアを、攻撃の道具やサービスとして提供するビジネス |
| ダークウェブ | 特殊なソフトでしかアクセスできない、匿名性の高いWeb。不正な取引に使われる |
| 脅威モデリング | システムに対する脅威を体系的に洗い出し、対策を検討する手法（STRIDEなど） |
| サイバーキルチェーン | 標的型攻撃を「偵察 → 武器化 → 配送 → 攻撃 → インストール → 遠隔操作 → 目的の実行」の段階に分けたモデル |
| ラテラルムーブメント | 侵入した端末から、社内の他の端末やサーバへ横方向に侵害を広げること |
| MITB攻撃 | ブラウザに感染したマルウェアが、通信内容を改ざんする（ネットバンキングの送金先の書換え） |
| リプレイ攻撃 | 盗聴した認証情報などをそのまま再送して、なりすます |
| オープンリダイレクト | 任意のURLへ転送してしまう機能を悪用し、正規サイト経由で偽サイトに誘導する |
| 第三者中継（オープンリレー） | 外部から外部へのメールを中継してしまうメールサーバ。迷惑メールの踏み台になる |
| SEOポイズニング | 検索結果の上位に悪意あるサイトが表示されるように細工する |
| バージョンロールバック攻撃 | 通信で、安全性の低い古いバージョンのプロトコルを使うように仕向ける（ダウングレード攻撃） |
| ディープフェイク | AIで作った本物そっくりの偽の映像・音声 |
| 敵対的サンプル | AIが誤認識するよう、人には分からない程度のノイズを加えたデータ |
| プロンプトインジェクション | 生成AIへの入力に細工した指示を混ぜ、本来の制限を破らせたり情報を漏らさせたりする攻撃 |
| フットプリンティング | 攻撃の前に、標的の情報を収集すること |
| やり取り型攻撃 | 何度か普通のメールをやり取りして信用させてから、マルウェア付きのメールを送る標的型攻撃 |

### 暗号・認証

| 用語 | 意味 |
|---|---|
| CRYPTREC暗号リスト | 日本の政府機関が推奨する安全な暗号の一覧 |
| XMLデジタル署名 | XML文書の全体や一部に付けるデジタル署名 |
| タイムスタンプ（時刻認証） | ある時刻にその電子文書が存在し、それ以降改ざんされていないことを第三者（TSA）が証明する |
| コードサイニング | ソフトウェアにデジタル署名を付け、作成者と改ざんがないことを証明する |
| Kerberos | 認証サーバが発行する「チケット」で、一度の認証で複数のサーバを利用できる認証方式 |
| 多段階認証 | 認証を複数回行う（同じ要素の場合もある）。多要素認証とは区別される |
| FIDO2・WebAuthn | パスワードを使わず、端末内の秘密鍵と生体認証などで認証する規格 |
| EMV 3-Dセキュア | 3-Dセキュアの新しい版。リスクベース認証で、怪しい取引のときだけ追加認証を求める |
| セキュリティトークン | ワンタイムパスワードを表示する小型の機器など |
| 行動的特徴による生体認証 | 声紋、署名の筆跡や筆圧、キーストロークなど、行動の癖で認証する |
| トラストアンカー・中間CA証明書 | 信頼の起点となる証明書（ルート証明書） ／ ルートCAとサーバ証明書の間をつなぐ中間認証局の証明書 |
| GPKI・BCA | 政府認証基盤 ／ 異なる認証基盤どうしを相互に信頼させるブリッジ認証局 |

| 情報セキュリティ事象・インシデント | セキュリティ上の問題の可能性がある出来事 ／ そのうち、業務に影響を与える可能性が高いもの |
