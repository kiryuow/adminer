試験直前に見返すための総まとめです。各章の「この章のまとめ」とあわせて、ここに載っている公式と用語の区別がすべて説明できれば、午前の基礎は十分です。

## 1. 必ず覚える公式・計算パターン

| 分野 | 公式・計算 | 章 |
|---|---|---|
| 基数 | nビットで 2<sup>n</sup> 通り。2<sup>10</sup>≒10<sup>3</sup>。2進⇔16進は4桁区切り | 1 |
| 補数 | 2の補数 ＝ ビット反転 ＋ 1。nビットの範囲 −2<sup>n−1</sup> 〜 2<sup>n−1</sup>−1 | 1 |
| 待ち行列 | ρ ＝ 到着率 × サービス時間。待ち時間 ＝ ρ/(1−ρ) × サービス時間 | 1 |
| 二分探索 | 最大比較回数 ≒ log<sub>2</sub>n ＋ 1。線形探索の平均は n/2 | 2 |
| CPU性能 | MIPS ＝ クロック周波数 ÷ CPI ÷ 10<sup>6</sup> | 3 |
| パイプライン | 所要サイクル ＝ ステージ数 ＋ (命令数 − 1) | 3 |
| キャッシュ | 実効アクセス時間 ＝ キャッシュ × ヒット率 ＋ 主記憶 × (1 − ヒット率) | 3 |
| HDD | 平均回転待ち時間 ＝ 1回転の時間 ÷ 2 | 3 |
| 稼働率 | MTBF ÷ (MTBF ＋ MTTR)。直列 a×b、並列 1−(1−a)(1−b) | 4 |
| データ量 | 画像 ＝ 画素数 × 色深度。音声 ＝ 周波数 × ビット数 × チャネル × 秒 | 6 |
| サブネット | ホスト数 ＝ 2<sup>ホスト部ビット数</sup> − 2 | 8 |
| 伝送時間 | データ量（ビット）÷（回線速度 × 伝送効率） | 8 |
| 鍵の数 | 共通鍵 n(n−1)/2、公開鍵 2n | 9 |
| EVM | SV＝EV−PV、CV＝EV−AC、SPI＝EV/PV、CPI＝EV/AC、EAC＝BAC/CPI | 11 |
| 経路の数 | コミュニケーション経路 ＝ n(n−1)/2 | 11 |
| 発注点 | 1日の使用量 × 調達期間 ＋ 安全在庫 | 16 |
| 損益分岐点 | 固定費 ÷ (1 − 変動費率) | 16 |
| 減価償却 | 定額法：取得価額 ÷ 耐用年数 | 16 |
| ベイズの定理 | P(A｜B) ＝ P(B｜A) × P(A) ÷ P(B)（全体のうち条件に合う割合） | 1 |
| 電池駆動時間 | 電池容量 ÷ 平均消費電流（動作・待機の時間比で加重平均） | 3 |
| 三点見積り | （楽観値 ＋ 4 × 最可能値 ＋ 悲観値）÷ 6 | 11 |
| 間接費の配賦 | 費用 × そのサービスの配賦基準値 ÷ 配賦基準値の合計 | 12 |
| MRP | 正味所要量 ＝ 総所要量 − 在庫（上位の階層から順に計算） | 16 |

## 2. まぎらわしい用語の区別

| これと | これの違い |
|---|---|
| 桁落ち（近い数の引き算） | 情報落ち（大きさが大きく違う数の足し算） |
| パリティ（1ビット誤りの検出のみ） | ハミング符号（1ビット訂正・2ビット検出） |
| スタック（LIFO） | キュー（FIFO） |
| DRAM（リフレッシュ必要・主記憶） | SRAM（フリップフロップ・キャッシュ） |
| ライトスルー（両方に同時書込み） | ライトバック（追い出し時に書き戻し） |
| フェールセーフ（安全側に止める） | フェールソフト（縮退して動き続ける） |
| スケールアップ（1台の性能を上げる） | スケールアウト（台数を増やす） |
| ファーストフィット（最初に見つかった領域） | ベストフィット（最小の十分な領域） |
| 差分バックアップ（前回フル以降） | 増分バックアップ（前回バックアップ以降） |
| WHERE（行を絞る） | HAVING（グループを絞る） |
| ロールバック（更新前ログで取消し） | ロールフォワード（更新後ログでやり直し） |
| TCP（コネクション型・高信頼） | UDP（コネクションレス・高速） |
| L2スイッチ（MACアドレス） | ルータ（IPアドレス） |
| 暗号化（受信者の公開鍵で暗号化） | デジタル署名（送信者の秘密鍵で署名） |
| IDS（検知・通知） | IPS（検知・遮断） |
| 同値分割（グループの代表値） | 限界値分析（境界の値） |
| スタブ（下位モジュールの代役） | ドライバ（上位モジュールの代役） |
| クラッシング（資源追加・コスト増） | ファストトラッキング（並行作業・手戻りリスク） |
| インシデント管理（迅速な回復） | 問題管理（根本原因の究明） |
| RTO（いつまでに復旧するか） | RPO（どの時点のデータまで戻すか） |
| RFI（情報提供依頼） | RFP（提案依頼） |
| BPR（抜本的な再設計） | BPM（継続的な改善） |
| スキミング（高価格で発売） | ペネトレーション（低価格で発売） |
| 請負（完成責任あり・指揮命令は受注者） | 派遣（完成責任なし・指揮命令は派遣先） |
| ノンプリエンプティブ（自ら手放すまで切り替えない） | プリエンプティブ（OSが強制的に切り替える） |
| FTA（トップ事象から原因へ：トップダウン） | FMEA（部品の故障から影響へ：ボトムアップ） |
| SoR（記録の正確さ） | SoE（顧客とのつながり） |
| コンティンジェンシー予備（既知のリスク） | マネジメント予備（未知のリスク） |
| ファブレス（工場を持たない） | ファウンドリ（製造だけを受託） |
| 検証（仕様どおりか） | 妥当性確認（ニーズを満たすか） |
| 著作権（登録不要・プログラムを保護） | 特許権（出願が必要・発明を保護） |

## 3. 試験当日のチェックリスト

- 受験票・身分証明書・筆記用具（鉛筆・消しゴム）・時計を準備したか（CBTの場合は案内に従う）
- 午前：1問に悩みすぎない。わからない問題は印を付けて後回しにし、最後に必ず全問マークする
- 午前：計算問題は問題用紙の余白で手順どおりに計算する。選択肢の数値から逆算するのも有効
- 午後：最初の5分で全問をざっと見て、選択する4問を決める。選択欄の問題番号を○で囲むのを忘れない
- 午後：1問30分を超えたら次の問題へ。空欄は作らない
- 午後：答えは問題文の言葉を使い、字数の8割以上を書く

:::point 最後に
応用情報技術者試験は範囲が広いですが、問われる内容の多くは「基本的な用語の正確な理解」と「定番の計算」です。本書で全体像をつかんだら、午前クイズと過去問で繰り返し確認し、午後対策シートで記述の練習を重ねていきましょう。合格を心から応援しています。
