## 1. 経営環境の分析

### SWOT 分析

自社の **内部環境** を強み（Strengths）・弱み（Weaknesses）、**外部環境** を機会（Opportunities）・脅威（Threats）に分けて整理する手法です。

| | プラスの要因 | マイナスの要因 |
|---|---|---|
| **内部環境**（自社でコントロールできる） | **S**：強み（技術力、ブランド） | **W**：弱み（資金不足、人材不足） |
| **外部環境**（自社ではコントロールできない） | **O**：機会（市場の拡大、規制緩和） | **T**：脅威（競合の参入、景気後退） |

:::point 内部か外部かで判断する
「競合他社が新製品を出した」→ 外部の脅威。「自社の営業力が高い」→ 内部の強み。迷ったら「自社の努力で変えられるか」で判断しましょう。SWOT を組み合わせて「強みを活かして機会をつかむ」などの戦略を考える手法を **クロスSWOT分析** といいます。
:::

### その他の分析手法

| 手法 | 内容 |
|---|---|
| **3C分析** | 顧客（Customer）・競合（Competitor）・自社（Company）の3つの視点で分析する |
| **PEST分析** | 政治（Politics）・経済（Economy）・社会（Society）・技術（Technology）のマクロ環境を分析する |
| **5フォース分析**（ファイブフォース） | 業界の収益性を決める5つの競争要因：①業界内の競合、②新規参入の脅威、③代替品の脅威、④買い手の交渉力、⑤売り手（供給業者）の交渉力 |
| **バリューチェーン分析** | 企業活動を、主活動（購買物流・製造・出荷物流・販売・サービス）と支援活動（人事・技術開発など）に分け、どこで価値（利益）が生まれているかを分析する |
| **VRIO分析** | 経営資源を、価値（Value）・希少性（Rarity）・模倣困難性（Imitability）・組織（Organization）で評価する |

### 成長戦略と競争戦略

**アンゾフの成長マトリクス**：「製品（既存・新規）」と「市場（既存・新規）」の組合せで、成長の方向性を4つに分けます。

| | 既存製品 | 新製品 |
|---|---|---|
| **既存市場** | 市場浸透（今の客にもっと売る） | 新製品開発 |
| **新市場** | 新市場開拓（新しい客に売る） | **多角化** |

**ポーターの競争の基本戦略**：

- **コストリーダーシップ戦略**：業界で最も低いコストを実現して、価格競争で優位に立つ。
- **差別化戦略**：品質・機能・ブランドなどで他社と違う価値を提供する。
- **集中戦略**：特定の顧客層や地域などに絞って、経営資源を集中する。

**コトラーの競争地位別戦略**：

| 地位 | 戦略 |
|---|---|
| **リーダー**（業界1位） | 市場全体の拡大、全方位戦略、同質化（他社の差別化を真似して打ち消す） |
| **チャレンジャー**（2位以下で1位を狙う） | リーダーとの **差別化** |
| **フォロワー** | リーダーの **模倣**。開発コストを抑える |
| **ニッチャー** | 大手が狙わない **隙間市場** に特化する |

### その他の戦略用語

- **コアコンピタンス**：他社が真似できない、自社の **核となる強み**（技術やノウハウ）。
- **アウトソーシング**：自社の業務を外部に委託する。コアコンピタンスに集中するために使う。
- **アライアンス**：他社との提携。**M&A**：企業の合併・買収。**TOB**：株式の公開買付け。**MBO**：経営陣による自社の買収。
- **ブルーオーシャン戦略**：競争の激しい既存市場（レッドオーシャン）ではなく、競争のない **新しい市場** を創造する。
- **ベンチマーキング**：優良企業の優れたやり方（ベストプラクティス）と比較し、自社の改善に取り入れる。

### CSF・KGI・KPI

- **KGI（重要目標達成指標）**：最終的な目標の達成度を測る指標（例：売上高を前年比10%増）。
- **CSF（重要成功要因）**：目標を達成するために、特に重要な要因（例：新規顧客の獲得）。
- **KPI（重要業績評価指標）**：CSF の達成度を測るための、途中経過の指標（例：月間の新規訪問件数）。
- **OKR**：野心的な目標（Objectives）と、その達成度を測る主要な成果（Key Results）を組み合わせた目標管理手法。

## 4. マーケティング

### マーケティングの基本

| 用語 | 内容 |
|---|---|
| **STP** | **セグメンテーション**（市場を細分化）→ **ターゲティング**（狙う市場を決める）→ **ポジショニング**（競合と比べた自社の立ち位置を決める） |
| **4P（売り手の視点）** | **Product**（製品）、**Price**（価格）、**Place**（流通）、**Promotion**（販売促進）。この組合せを **マーケティングミックス** という |
| **4C（買い手の視点）** | Customer Value（顧客価値）、Cost（顧客の負担）、Convenience（入手の容易さ）、Communication（対話） |
| **プロダクトライフサイクル** | 製品の一生を **導入期 → 成長期 → 成熟期 → 衰退期** に分ける。成長期は競合が増え、成熟期は差別化や価格競争が重要 |
| **AIDMA** | 消費者の購買行動：Attention（注意）→ Interest（関心）→ Desire（欲求）→ Memory（記憶）→ Action（行動）。ネット時代は **AISAS**（Search・Share が入る） |

### 価格戦略・販売の手法

- **スキミングプライシング（上澄み吸収価格）**：新製品を **高い価格** で発売し、早く開発費を回収する。
- **ペネトレーションプライシング（市場浸透価格）**：**低い価格** で発売し、一気にシェアを獲得する。
- **ダイナミックプライシング**：需要と供給の状況に応じて、価格を変動させる（航空券、ホテル）。
- **オムニチャネル**：店舗、通販サイト、SNS などのあらゆる販売チャネルを連携させ、顧客がどこからでも同じように購入できるようにする。
- **アフィリエイト**：自分のサイトに企業の広告を載せ、そこから商品が購入されると報酬を得る。
- **ロングテール**：ネット販売では、販売数の少ない多数のニッチ商品の売上合計が、大きな割合を占めるという現象。
- **インバウンドマーケティング**：有益な情報を発信して、顧客の方から見つけてもらう手法。
- **RFM分析**：顧客を **R**ecency（最終購買日）・**F**requency（購買頻度）・**M**onetary（購買金額）で分析し、優良顧客を見つける。

## 5. 技術戦略（MOT）

**MOT（技術経営）** とは、技術開発の成果を、事業の成功と利益に結び付けるための経営の考え方です。

- **技術ロードマップ**：将来の技術の進化や市場の変化を予測し、どの技術をいつまでに開発するかを、時間軸に沿って示した図。
- **魔の川・死の谷・ダーウィンの海**：研究開発が事業化するまでの3つの障壁。基礎研究→製品開発（魔の川）、製品開発→事業化（死の谷：資金不足など）、事業化→産業化（ダーウィンの海：市場での競争）。
- **イノベーションのジレンマ**：優良企業が、既存の顧客の要望に応えて製品を改良し続けた結果、新しい技術（破壊的イノベーション）を軽視して、市場を奪われてしまう現象。
- **オープンイノベーション**：自社だけでなく、大学や他社などの外部の技術やアイデアを積極的に取り入れて、新しい価値を生み出す。
- **ハイプサイクル**：新しい技術への期待が「黎明期 → 過度な期待のピーク期 → 幻滅期 → 啓蒙活動期 → 生産性の安定期」と推移することを示した図（ガートナー社）。
- **キャズム**：新しい製品が、初期の利用者（アーリーアダプター）から多数派（アーリーマジョリティ）に普及する間にある、大きな溝。
- **デザイン思考**：利用者の視点に立ち、「共感 → 問題定義 → 創造 → 試作 → テスト」を繰り返して、課題解決の方法を見つける。
- **PoC（概念実証）**：新しいアイデアや技術が実現可能か、効果があるかを、小規模に試して検証すること。

## 6. ビジネスインダストリ（ITの活用分野）

### e-ビジネス

| 用語 | 内容 |
|---|---|
| **EC（電子商取引）** | **BtoB**（企業間）、**BtoC**（企業と消費者）、**CtoC**（消費者間：フリマアプリ）、**GtoC**（行政と市民） |
| **EDI（電子データ交換）** | 企業間で、受発注などの取引データを、標準化された形式で電子的に交換する |
| **O2O**（Online to Offline） | ネット上でクーポンを配るなどして、実店舗への来店を促す |
| **シェアリングエコノミー** | 個人が持つ車や部屋などを、インターネットを介して他者と共有・貸し借りする |
| **サブスクリプション** | 製品やサービスを所有せず、一定期間の利用権に対して料金を払う |
| **クラウドファンディング** | インターネットを通じて、不特定多数の人から資金を集める |
| **フィンテック（FinTech）** | 金融（Finance）と技術（Technology）を融合した新しいサービス（スマホ決済、ロボアドバイザ） |
| **暗号資産** | ブロックチェーン技術を使った、インターネット上の財産的価値 |

### 産業での IT 活用

- **IoT**：あらゆるモノがインターネットにつながり、データを収集・活用する。
- **インダストリー4.0**：IoT・AI で工場の生産をスマート化する、ドイツ発の構想。**スマートファクトリー**。
- **CAD / CAM**：コンピュータを使った設計 / 製造。
- **MRP（資材所要量計画）**：生産計画と部品表（BOM）から、必要な部品の量と時期を計算する。
- **JIT（ジャストインタイム）**：必要なものを、必要なときに、必要な量だけ生産する。トヨタの **かんばん方式** が代表。
- **POS システム**：販売時点で、商品の販売情報を収集・管理する。売れ筋分析に使う。
- **GPS・GIS**：位置情報の取得 / 地図と情報を重ねて表示・分析する。
- **MaaS**：電車・バス・タクシーなどの複数の交通手段を、1つのサービスとして検索・予約・決済できるようにする。
- **スマートグリッド**：IT を活用して、電力の需要と供給を効率的に制御する次世代の送電網。
- **Society 5.0**：サイバー空間と現実空間を高度に融合させたシステムにより、経済発展と社会的課題の解決を両立する、人間中心の社会（日本政府が提唱）。

### 組込みシステムと IoT の構成

- **組込みシステム**：家電、自動車、産業機器などに組み込まれ、特定の機能を実現するコンピュータシステム。リアルタイム性・省電力・小型化が求められる（第3章、第5章）。
- **IoT のシステム構成**：デバイス（センサー）→ ゲートウェイ（エッジ）→ ネットワーク → クラウド（データ分析）。

## 7. 過去問（令和2〜6年度）で問われた発展テーマ

### ゲーム理論（令和4年度春期 午後問2、令和6年度春期 午前）

**ゲーム理論** は、複数のプレイヤーが、互いの行動を予想しながら自分の利益が最大になる行動を選ぶ状況を分析する理論です。

- **ナッシュ均衡**：どのプレイヤーも、**自分だけが戦略を変えても利益が増えない** 状態。互いに相手の戦略に対する最善の策をとっている、安定した組合せ。
- **囚人のジレンマ**：お互いが協力すれば両者にとって良い結果になるのに、各自が自分の利益を優先すると、両者にとって悪い結果（ナッシュ均衡）に落ち着いてしまう状況。
- **ゼロサムゲーム**：一方の利益が、そのまま他方の損失になるゲーム（利益の合計が常に0）。

### 知識・人材の経営

- **SECI モデル**（令和5年度秋期 午後問2）：個人が持つ言葉にしにくい知識（**暗黙知**）と、文章や図にできる知識（**形式知**）を変換しながら、組織の知識を生み出すプロセス。
    - **共同化**（Socialization）：暗黙知 → 暗黙知（体験の共有、OJT）
    - **表出化**（Externalization）：暗黙知 → 形式知（マニュアル化）
    - **連結化**（Combination）：形式知 → 形式知（複数の文書を組み合わせて新しい知識を作る）
    - **内面化**（Internalization）：形式知 → 暗黙知（マニュアルを実践して身に付ける）
- **ナレッジマネジメント**：社員が持つ知識やノウハウを組織全体で共有・活用する経営手法。
- **人的資本経営**：人材を「コスト」ではなく「**資本**」ととらえ、教育などへの投資によって価値を高め、企業価値の向上につなげる考え方。
- **サービスプロフィットチェーン**（令和6年度秋期 午後問2）：**従業員満足** の向上 → サービス品質の向上 → **顧客満足** の向上 → 顧客ロイヤルティの向上 → **売上・利益の増加** という因果の連鎖を示したモデル。
- **ERRC グリッド**：ブルーオーシャン戦略で使う枠組み。業界の常識となっている要素を、**取り除く（Eliminate）・減らす（Reduce）・増やす（Raise）・付け加える（Create）** の4つの観点で見直し、新しい価値を作る。

### リーダーシップ論と組織行動

| 理論 | 内容 |
|---|---|
| **SL理論**（ハーシィ＆ブランチャード） | **部下の成熟度（能力と意欲）** に応じて、リーダーシップのスタイルを「指示型 → 説得型（コーチ型） → 参加型（支援型） → 委任型」と変えるべきだとする |
| **PM理論**（三隅二不二） | リーダーシップを **P（Performance：目標達成機能）** と **M（Maintenance：集団維持機能）** の2つの軸で分類し、両方とも高い「PM型」が最も望ましいとする |
| **コンティンジェンシー理論**（フィードラー） | 最適なリーダーシップのスタイルは、**状況**（リーダーと部下の関係、仕事の明確さ、リーダーの権限）によって変わるとする |
| **ファシリテーター** | 会議で、中立的な立場から **参加者の発言を促し、議論を整理して、合意形成を支援する** 進行役。自分の意見で結論を導くのではない |

### 生産・製造のビジネスモデル

- **ファブレス**：自社で **工場を持たず**、製品の企画・設計・販売に特化し、製造は外部に委託する。
- **ファウンドリ**：他社から委託を受けて、半導体などの **製造だけを専門に** 行う。
- **EMS**（Electronics Manufacturing Services）：電子機器の製造を、受託して行うサービス（設計から製造・修理まで請け負うこともある）。
- **マスカスタマイゼーション**：大量生産の効率を保ちながら、顧客一人ひとりの好みに合わせた **個別仕様の製品** を作る。IoT やデジタル技術で実現する。
- **セル生産方式**：1人または少人数のチームが、製品の組立ての全工程を担当する。多品種少量生産に向く。

### 価格設定・その他の用語

- **ターゲットリターン価格設定**：目標とする **投資収益率（利益）** を達成できるように価格を決める。
- **バリュープライシング**：顧客が感じる価値に基づいて価格を決める。
- **デューデリジェンス**：M&A の際に、買収する側が、相手企業の財務状況・資産・負債・法的リスク・企業価値などを **詳しく調査** すること。
- **デルファイ法**：複数の専門家に意見を聞き、その結果をフィードバックして再び意見を聞くことを **繰り返して**、意見を収束させる予測手法。
- **ギグエコノミー**：インターネットを通じて **単発の仕事** を受注する働き方や、それによって成り立つ経済。
- **フィルタバブル**：検索サイトや SNS が利用者の好みに合わせた情報ばかりを表示するため、利用者が **自分の見たい情報だけに囲まれ（泡の中に閉じ込められ）**、異なる意見に触れにくくなる現象。
- **アグリゲーションサービス**：複数のサービスに分散している情報を **集約して一元的に表示** するサービス。例：複数の銀行口座やクレジットカードの残高・明細を1つのアプリでまとめて見られる。

### IT を活用した産業の動向

- **CPS（サイバーフィジカルシステム）**：現実世界（フィジカル空間）のデータをセンサーで集め、サイバー空間で分析し、その結果を現実世界にフィードバックして、社会や産業を最適化する仕組み。**デジタルツイン** はその代表例。
- **マシンビジョン**：工場で、カメラの画像を AI などで解析して、製品の **外観検査** や部品の位置の認識を自動化する。
- **エッジコンピューティング**：IoT 機器の近く（エッジ）でデータを処理し、クラウドへの通信量と応答の遅れを減らす。
