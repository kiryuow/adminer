## 過去の午前で実際に出た用語

| 用語 | 意味 |
|---|---|
| L2TP | Layer 2 Tunneling Protocol。データリンク層（PPPフレーム）をIPネットワーク上でトンネリングするプロトコル。**暗号化機能を持たない** ため、IPsecと組み合わせて（L2TP/IPsec）VPNに使う |
| PSK（事前共有鍵） | Pre-Shared Key。通信する両者があらかじめ同じ鍵（パスフレーズ）を設定しておく方式。WPA2/WPA3-パーソナルやIPsecで使う。鍵が漏れると全員の通信が危険になる |
| RFID | 電波を使い、ICタグ（RFタグ）の情報を非接触で読み書きする技術。物流の在庫管理や交通系ICカードで使う。バーコードと違い、**複数のタグを一度に、箱の中でも読める** |
| PSIRT | Product Security Incident Response Team。自社が **出荷した製品** の脆弱性に対応する組織（社内システムを守るCSIRTと区別） |
| J-CRAT（サイバーレスキュー隊） | IPAが設置した、標的型サイバー攻撃の被害の拡大を防ぐために組織を支援する活動。相談を受けて初動対応を助言する |
| ESD（静電気放電）と耐タンパ性 | 耐タンパ性は、ICチップなどを解析・改ざんしにくくする性質。攻撃者は電源電圧の変動、静電気放電、クロック操作などで誤動作させて秘密情報を盗もうとする（故障利用攻撃）。対策として、異常を検知したら内部データを消去する |
| サイドチャネル攻撃（補足） | 処理時間・消費電力・電磁波などの物理的な情報から暗号鍵を推測する攻撃。耐タンパ性の対策の対象 |
| ボットネット | マルウェアに感染して攻撃者の指令（C&Cサーバ）で操られるコンピュータ（ボット）の集まり。DDoS攻撃やスパム送信に使われる |
| コプロセッサ | CPUを補助して、浮動小数点演算・暗号処理・画像処理などの特定の処理を担当するプロセッサ |
| ADPCM | 適応的差分パルス符号変調。前の標本値との **差分** を符号化し、差分の大きさに合わせて量子化幅を変える音声圧縮方式。PCMよりデータ量が少ない |
| ビットカラー（色深度） | 1画素の色を表すビット数。nビットなら 2ⁿ 色。24ビットカラー＝RGB各8ビット＝約1,677万色（フルカラー）。画像容量＝画素数×ビット数÷8（バイト） |
| ワンセグ | 地上デジタル放送の1チャネル（13セグメント）のうち1セグメントを使った携帯端末向け放送 |
| レイトレーシング法 | 視点から画素ごとに光線（レイ）を逆にたどり、反射・屈折・影を計算して描く3次元CGの手法。鏡面の映り込みの表現に強い |
| ラジオシティ法 | 物体の表面どうしの **光の相互反射**（拡散反射）を計算して、間接光による柔らかい明るさを描く手法 |
| メタボール | 球などを、互いに近づくと滑らかに融合する「濃度の場」で表し、液体や生物のような曲面を作るモデリング手法 |
| テクスチャマッピング・Zバッファ法（復習） | 表面に画像を貼り付ける手法 ／ 画素ごとに奥行き（Z値）を比べ、手前の物体だけを描く隠面消去法 |
| マスタファイル・トランザクションファイル | 基本的で長期間使うデータ（顧客・商品など）のファイル ／ 日々発生する取引データのファイル。バッチ処理ではトランザクションファイルでマスタファイルを更新する |
| 名寄せ | 複数のデータの中から、同じ人や同じ企業のデータを見つけて1つにまとめること |
| ビジネスインテリジェンス（BI） | 企業に蓄積したデータを集計・分析・可視化して、経営の意思決定に役立てる手法・ツール（OLAP、ダッシュボード、データマイニング） |
| HRM（人的資源管理） | Human Resource Management。採用・配置・評価・育成・報酬などを通じて、人材を経営資源として活かす管理。HRテックはこれをITで支援するもの |
| プライスライニング | 価格帯をいくつかの段階（例：1,000円・3,000円・5,000円）に絞って品ぞろえし、顧客が選びやすくする価格設定 |
| ゴードン法 | ブレーンストーミングの一種。参加者に **本当のテーマを伏せ**、抽象化した課題で自由に発想させてから、リーダーが本題に結び付ける |
| NM法 | 発想法の一つ。テーマのキーワードから類比（アナロジー）を考え、その背景・構造から新しい発想を得る |
| その他の発想法 | **KJ法**（カードをグループ化して整理）、**ブレーンストーミング**（批判禁止・自由奔放・質より量・結合改善）、**親和図法**、**特性要因図**（復習） |

## シラバス Ver.7.2 の用語例の補足

| 用語 | 意味 |
|---|---|
| UCS（Unicode） | 世界の文字を1つの体系で表す文字コード（国際規格 ISO/IEC 10646）。符号化方式に UTF-8（1〜4バイトの可変長、ASCIIと互換）、UTF-16 がある |
| ハイパースカラ | 1クロックで複数の命令を同時に発行・実行できるように、パイプラインを複数持つCPUの方式（スーパースカラと同じ意味で使われる） |
| マイクロプログラム制御 | 機械語命令を、さらに細かいマイクロ命令の列で実行する制御方式。次に実行するマイクロ命令の位置を **マイクロプログラムカウンタ** が示す。対になるのは配線論理（ワイヤードロジック）方式 |
| DDR SDRAM の世代 | クロックの立上りと立下りの両方でデータを転送するDRAM。DDR2→DDR3→DDR4→DDR5 と世代ごとに転送速度が上がり、電圧が下がる。世代間で互換性はない |
| フラッシュブートローダ | 組込み機器で、フラッシュメモリ上のプログラムを書き換えたり、起動時にプログラムを読み込んだりする小さなプログラム |
| システムモニタ | OSやサーバの稼働状況（CPU・メモリ・ディスク・プロセス）を監視・表示するソフトウェア |
| OSE（Open Systems Environment） | 国際標準などの **オープンな仕様**（POSIXなど）に基づき、アプリケーションの移植性・相互運用性を確保したシステム環境。特定メーカーに依存しない「オープンOS」と同じ考え方 |
| SDL・ADL | 仕様記述言語（Specification and Description Language：通信システムの振る舞いを状態遷移で記述）／ アーキテクチャ記述言語（Architecture Description Language：ソフトウェアの構成要素と接続を記述） |
| コンポジット構造図 | UMLの構造図の一つ。クラスの **内部構造**（部品と、部品どうしの接続・ポート）を表す |
| XHTML Basic・XHTML Modularization | 携帯端末向けに機能を絞ったXHTML ／ XHTMLの機能をモジュールに分割し、必要なものを組み合わせられるようにした仕様 |
| JIS X 7011・7012 | EDI（電子データ交換）の標準。国連の EDIFACT に対応する JIS で、7011 はメッセージの構文規則、7012 はデータ項目（貿易データ要素）の辞書を定める。XBRL・ebXML・XML-EDI と並ぶデータ交換の標準 |
| リスクコミュニケーション | リスクの情報を、組織の利害関係者の間で共有し、相互に理解を深めること |
| リスクヘッジ | 損失の可能性を、別の取引や手段で相殺・軽減すること（リスク対応の「移転」「低減」に近い考え方） |
| セキュリティクリアランス | 国の機密情報を扱う人の **適格性を事前に審査** し、資格のある人だけに情報へのアクセスを認める制度。日本では「重要経済安保情報保護活用法」（2025年施行）で導入 |
| エシカルハッカー | 組織の許可を得て、攻撃者と同じ手法でシステムの弱点を調べる専門家（ホワイトハッカー）。ペネトレーションテストを担う |
| ハウジングセキュリティ | 事業者のデータセンタに自社の機器を設置（ハウジング）するときの物理的・人的なセキュリティ（入退室管理、監視カメラ、ラック施錠） |
| プライバシーフレームワーク | 個人情報・プライバシーを保護するための考え方の枠組み（ISO/IEC 29100）。プライバシーバイデザインと合わせて覚える |
| Trusted Web 推進協議会 | 内閣官房が設置した、インターネット上でやり取りするデータや相手が信頼できることを検証できる仕組み（Trusted Web）の実現を目指す協議会 |
| ベイジアン理論（ベイズの定理） | 新しい観測結果によって、事前の確率を事後の確率に更新する考え方。迷惑メールフィルタ（ベイジアンフィルタ）や機械学習で使う |
| 時系列分析 | 時間の経過に沿って並んだデータ（売上の月次推移など）から、傾向（トレンド）・季節変動・不規則変動を分けて分析し、将来を予測する手法。移動平均法・指数平滑法を使う |
| 質問紙法・フォーカスグループ | アンケート用紙で多数の回答を集める調査 ／ 少人数の対象者を集めて座談会形式で意見を引き出す定性調査 |
| 内部分析・外部分析 | 自社の経営資源（強み・弱み）の分析 ／ 市場・競合・マクロ環境（機会・脅威）の分析。SWOT分析はこの2つを合わせたもの |
| 静態分析・動態分析 | ある時点の財務状態（貸借対照表）を見る分析 ／ 一定期間の流れ（損益計算書・キャッシュフロー計算書）を見る分析 |
| キャッシュマネジメント | 企業グループ内の資金を集中管理して、余剰資金と不足資金を融通し、資金効率を高める仕組み（CMS） |

</div>

:::point 精査の結論
付録A〜Fまでで、シラバス Ver.7.2 の用語例と、平成28年度〜令和7年度の午前試験で実際に問われた用語の大部分を説明しました。残る用語の多くは、出題されても選択肢の一つ（誤答）として現れる程度のものです。
:::
