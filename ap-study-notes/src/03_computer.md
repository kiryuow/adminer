## 1. CPU の構成と命令の実行

### CPU の中身

- **制御装置**：主記憶から命令を取り出し、解読して、各装置に指示を出す。
- **演算装置（ALU）**：足し算・論理演算などの計算をする。
- **レジスタ**：CPU内部の超高速な小さい記憶場所。主なものは次のとおり。

| レジスタ | 役割 |
|---|---|
| プログラムカウンタ（PC） | **次に実行する命令のアドレス** を保持する |
| 命令レジスタ | 取り出した命令そのものを保持する |
| 汎用レジスタ／アキュムレータ | 演算対象のデータや結果を保持する |
| インデックスレジスタ | アドレス計算に使う値（添字）を保持する |
| フラグレジスタ（状態レジスタ） | 演算結果がゼロ、負、桁あふれなどの状態を保持する |

### アドレス指定方式

命令の中の「アドレス部」の値から、実際にデータがある場所（**実効アドレス**）を求める方法です。

| 方式 | 実効アドレスの求め方 |
|---|---|
| 即値アドレス指定 | アドレス部の値そのものがデータ（アドレスではない） |
| 直接アドレス指定 | アドレス部の値 ＝ 実効アドレス |
| 間接アドレス指定 | アドレス部が指す場所に書かれている値 ＝ 実効アドレス |
| インデックス（指標）アドレス指定 | アドレス部 ＋ インデックスレジスタの値 |
| ベースアドレス指定 | アドレス部 ＋ ベースレジスタの値 |
| 相対アドレス指定 | アドレス部 ＋ プログラムカウンタの値 |

## 2. CPU の性能指標

- **クロック周波数**：CPUが動作するリズムの速さ。1GHz なら1秒間に10億回刻む。1クロックの時間（**クロックサイクル時間**）は 1 ÷ 周波数。1GHz なら 1ナノ秒。
- **CPI（Cycles Per Instruction）**：1命令の実行に必要な平均クロック数。
- **MIPS（Million Instructions Per Second）**：1秒間に何百万命令を実行できるか。
- **FLOPS**：1秒間に何回の浮動小数点演算ができるか。スーパーコンピュータの性能指標。

:::calc MIPS の計算
クロック周波数 2GHz、平均 CPI が 4 の CPU の性能は何 MIPS？
1秒間のクロック数 ＝ 2,000,000,000 回。1命令 ＝ 4 クロックなので、1秒間の命令数 ＝ 2,000,000,000 ÷ 4 ＝ 500,000,000 ＝ **500 MIPS**
1命令の平均実行時間 ＝ 1 ÷ 5億 ＝ **2ナノ秒**
:::

:::calc 命令ミックスから平均 CPI を求める
命令Aが CPI 2 で出現率60%、命令Bが CPI 5 で出現率40%。
平均 CPI ＝ 2 × 0.6 ＋ 5 × 0.4 ＝ 1.2 ＋ 2.0 ＝ **3.2**
:::

:::exam R7秋 午前問11
HPC（高性能計算）マシンの構成を更新したときのノード数と総理論ピーク演算性能を求める問題。「1コアの性能 × 1ノードのコア数 × ノード数 ＝ 総性能」という掛け算の関係を整理すれば解けます。単位（GFLOPS → TFLOPS は1,000倍）にも注意します。
:::

:::calc パイプラインの実行時間
ステージ数 k、命令数 n のとき、所要サイクル数 ＝ **k ＋ (n − 1)**。
5ステージで10命令なら 5 ＋ 9 ＝ 14 サイクル（パイプラインなしなら 50 サイクル）。

:::note パイプラインハザード
パイプラインの流れが乱れて性能が落ちることを **ハザード** といいます。
**構造ハザード**：同じ装置を同時に使おうとして衝突する。**データハザード**：前の命令の結果を次の命令が使うため待たされる。**制御ハザード**：分岐命令で次に実行する命令が決まらず、先読みした命令が無駄になる。対策として **分岐予測** や **投機実行** があります。
:::

### その他の高速化技術

| 技術 | 内容 |
|---|---|
| **スーパースカラ** | パイプラインを複数本持ち、同時に複数の命令を実行する |
| **スーパーパイプライン** | パイプラインのステージをさらに細かく分割し、クロックを速くする |
| **VLIW** | **コンパイルの段階で**、同時に実行できる複数の命令を1つの長い命令にまとめる |
| **マルチコア** | 1つのCPUの中に複数のコア（演算の中核）を持ち、並列処理する |
| **SIMD** | 1つの命令で複数のデータを同時に処理する（画像処理、GPU） |
| **MIMD** | 複数のプロセッサがそれぞれ別の命令で別のデータを処理する |

「同時に実行可能な複数の動作を、コンパイルの段階でまとめて一つの複合命令とする方式」を選ぶ問題。キーワード「コンパイルの段階でまとめる」→ **VLIW**（Very Long Instruction Word）です。
:::

### RISC と CISC

| | RISC（縮小命令セット） | CISC（複合命令セット） |
|---|---|---|
| 命令の種類 | 少なく単純 | 多く複雑 |
| 命令の長さ | 固定長 | 可変長 |
| 制御方式 | **ワイヤードロジック**（回路で直接実行） | **マイクロプログラム** |
| 特徴 | パイプラインと相性が良い。スマホのARMなど | 1命令で複雑な処理ができる。x86など |

### マルチプロセッサとアムダールの法則

- **密結合マルチプロセッサ**：複数のプロセッサが主記憶を共有する。
- **疎結合マルチプロセッサ**：プロセッサごとに主記憶を持ち、通信で連携する。
- **アムダールの法則**：プログラムのうち並列化できない部分があると、プロセッサを増やしても性能向上には限界がある、という法則。

:::calc アムダールの法則
処理の80%が並列化可能。プロセッサを4台にすると何倍速くなる？
所要時間 ＝ 並列化できない20% ＋ 並列化できる80%÷4 ＝ 0.2 ＋ 0.2 ＝ 0.4 → 速度は 1 ÷ 0.4 ＝ **2.5倍**（4倍にはならない）
:::

## 4. メモリ

### 半導体メモリの種類

| 種類 | 特徴 | 用途 |
|---|---|---|
| **DRAM** | コンデンサに電荷をためて記憶。**リフレッシュ（再書込み）が必要**。安価で大容量 | 主記憶 |
| **SRAM** | **フリップフロップ** 回路で記憶。リフレッシュ不要。高速だが高価 | キャッシュメモリ |
| **フラッシュメモリ** | 電源を切っても内容が消えない（**不揮発性**）。ブロック単位で消去 | SSD、USBメモリ |
| **ROM** | 読出し専用。不揮発性 | ファームウェア |

- **揮発性**：電源を切ると内容が消える（DRAM, SRAM）。**不揮発性**：消えない（フラッシュ, ROM）。

### キャッシュメモリ

**キャッシュメモリ** は、CPUと主記憶の速度差を埋めるために間に置く、高速・小容量のメモリです。よく使うデータをキャッシュに置いておき、CPUはまずキャッシュを探します。キャッシュにデータがあることを **ヒット**、ないことを **ミス** といい、ヒットする割合を **ヒット率** といいます。

:::calc 実効アクセス時間
キャッシュのアクセス時間 10ns、主記憶のアクセス時間 60ns、ヒット率 90% のとき、平均（実効）アクセス時間は？
実効アクセス時間 ＝ キャッシュ時間 × ヒット率 ＋ 主記憶時間 × (1 − ヒット率)
＝ 10 × 0.9 ＋ 60 × 0.1 ＝ 9 ＋ 6 ＝ **15ns**
:::

- **ライトスルー方式**：書込み時、キャッシュと主記憶の **両方に同時に** 書く。一貫性は保ちやすいが遅い。
- **ライトバック方式**：書込み時はキャッシュだけに書き、キャッシュから追い出すときに主記憶へ書き戻す。速いが制御が複雑。
- **マッピング方式**：主記憶のどのブロックをキャッシュのどこに置くか。**ダイレクトマッピング**（置き場所が1か所に決まる）、**フルアソシアティブ**（どこにでも置ける）、**セットアソシアティブ**（決まったグループ内ならどこでもよい）。
- **局所性**：プログラムは「最近使ったデータをまた使う（時間的局所性）」「近くのアドレスを続けて使う（空間的局所性）」傾向がある。これがキャッシュが効く理由。

:::note メモリインタリーブ
主記憶を複数のバンク（区画）に分け、連続したアドレスを別々のバンクに割り当てて、並行してアクセスすることで高速化する技術です。
:::

### ユニファイドメモリ

**ユニファイドメモリ方式** とは、CPUとGPU（画像処理装置）が **主記憶を共有する** 方式です。画面表示用の領域（フレームバッファ）も主記憶の一部を使います。専用のビデオメモリを持たないので安価・省電力ですが、主記憶の帯域を分け合います。

:::exam R7秋 午前問9
フレームバッファがユニファイドメモリ方式であるシステムの特徴を問う問題。「主記憶の一部を表示領域として使用する」が正解です。
:::

## 5. 補助記憶装置

### HDD（ハードディスク）

磁気ディスク（円盤）を回転させ、磁気ヘッドでデータを読み書きします。

- **アクセス時間 ＝ 平均シーク時間 ＋ 平均回転待ち時間 ＋ データ転送時間**
- **シーク時間**：ヘッドを目的のトラック（同心円）まで動かす時間。
- **平均回転待ち時間**：目的のデータがヘッドの下に来るまで待つ時間。平均は **1回転の半分**。

:::calc 平均回転待ち時間
6,000回転/分のHDDの平均回転待ち時間は？
1秒間に 6,000 ÷ 60 ＝ 100回転 → 1回転 ＝ 10ミリ秒 → 平均回転待ち時間 ＝ その半分 ＝ **5ミリ秒**
:::

### SSD

フラッシュメモリを使った補助記憶装置です。機械的な動作がないので高速・低消費電力・衝撃に強い反面、書換え回数に上限があります。同じ場所への書込みが集中しないように分散させる **ウェアレベリング** という技術を使います。

### RAID

複数のディスクを組み合わせて、速度や信頼性を高める技術です。

| レベル | 方式 | 特徴 |
|---|---|---|
| RAID 0 | **ストライピング**：データを複数ディスクに分散して書く | 高速。冗長性なし（1台壊れると全データ消失） |
| RAID 1 | **ミラーリング**：同じデータを2台に書く | 信頼性が高い。容量効率50% |
| RAID 5 | ストライピング＋**パリティ**を分散して記録 | 1台が故障しても復元可能。3台以上必要 |
| RAID 6 | パリティを2種類記録 | 2台同時故障まで耐える |
| RAID 1+0 | ミラーリングしたものをストライピング | 高速かつ高信頼 |

## 6. 入出力インタフェースと入出力制御

| インタフェース | 特徴 |
|---|---|
| USB | シリアル。ホットプラグ（電源を入れたまま抜き差し）可能。バスパワーで給電 |
| HDMI | 映像と音声をデジタルで1本のケーブルで伝送 |
| Bluetooth | 近距離無線。キーボード、イヤホンなど |
| NFC | 10cm程度の超近距離無線。ICカード、スマホ決済 |
| I<sup>2</sup>C | 組込み機器で、センサーなど複数のデバイスを2本の信号線（バス）で接続する |
| PCI Express | 拡張カードやSSD（NVMe）を接続する高速なシリアルインタフェース |

- **DMA（直接メモリアクセス）**：CPUを介さずに、入出力装置と主記憶の間で直接データを転送する方式。CPUの負担が減る。
- **割込み**：実行中の処理を一時中断して、緊急の処理を優先させる仕組み。**外部割込み**（入出力完了、タイマ、電源異常など）と **内部割込み**（ゼロ除算、ページフォールト、ソフトウェア割込み＝スーパバイザコールなど）がある。

## 7. ハードウェアと組込みシステム

### 電子部品と論理回路

- **FPGA**：製造後に利用者が回路の構成を **書き換えられる** 集積回路。試作や少量生産に向く。
- **ASIC**：特定の用途向けに設計・製造された専用の集積回路。大量生産で安価・高性能。
- **SoC（System on a Chip）**：CPU、メモリ、周辺回路など、システムに必要な機能を1つのチップにまとめたもの。
- **A/D変換**：アナログ信号をデジタル値に変換する。サンプリング（標本化）→ 量子化 → 符号化 の順。
- **PWM制御**：パルスのON時間の割合（**デューティ比**）を変えて、モーターの回転速度やLEDの明るさを制御する方式。

### センサーとアクチュエータ

**センサー** は温度・光・加速度などの物理量を電気信号に変える部品、**アクチュエータ** は電気信号を動き（モーターの回転など）に変える部品です。組込みシステムは「センサーで測る → CPUで判断 → アクチュエータで動かす」という流れで動きます。

:::calc 回転数をパルスから求める
1MHz（1秒間に100万カウント）のタイマで、センサーのパルス1周期を測ったら 10,000 カウントだった。1回転で2パルス出るとき、回転数は毎秒何回転？
1パルスの周期 ＝ 10,000 ÷ 1,000,000 ＝ 0.01秒 → 1回転 ＝ 2パルス ＝ 0.02秒 → 1秒間に 1 ÷ 0.02 ＝ **50回転**
（R7秋 午前問10 で問われた考え方です）
:::

### 電力と省エネ

- **DVFS**：処理の負荷に応じて、電圧とクロック周波数を動的に変えて消費電力を下げる技術。
- **パワーゲーティング**：使っていない回路への電源供給を止める。
- **クロックゲーティング**：使っていない回路へのクロック供給を止める。

## 8. 過去問（令和2〜6年度）で問われた発展テーマ

### スタックポインタとヘテロジニアスマルチコア

- **スタックポインタ**：主記憶上のスタック領域で、**現在の先頭（最後に積んだデータ）の位置** を指すレジスタ。サブルーチン（関数）を呼び出すときは戻り先アドレスをスタックに積み、戻るときに取り出す。
- **ヘテロジニアスマルチコア**：性質の異なる複数の種類のコアを1つのプロセッサに搭載する方式。スマートフォンでは、**高性能なコアと省電力のコアを組み合わせ**、負荷に応じて使い分けて性能と省電力を両立する（big.LITTLE）。
- **GPU**：画像処理用に、単純な演算器を数千個並べて **大量の並列計算** を行うプロセッサ。AI の学習や科学技術計算にも使われる（**GPGPU**）。

### 2段のキャッシュ

:::calc L1・L2キャッシュの実効アクセス時間
L1 のアクセス時間 1ns・ヒット率 90%、L2 のアクセス時間 5ns・ヒット率 95%（L1でミスしたアクセスのうち）、主記憶 50ns。
・L1 でヒット：0.9 × 1 ＝ 0.9
・L1 でミス、L2 でヒット：0.1 × 0.95 × 5 ＝ 0.475
・両方ミスで主記憶：0.1 × 0.05 × 50 ＝ 0.25
実効アクセス時間 ＝ 0.9 ＋ 0.475 ＋ 0.25 ≒ **1.6ns**（問題によってはミス時に各段のアクセス時間を足し合わせる場合もあるので、問題文の条件に従います）
:::

### 電子部品と回路

| 部品 | 働き |
|---|---|
| **抵抗** | 電流の流れを妨げ、電流や電圧を調整する |
| **コンデンサ** | 電荷をためたり放出したりする。**直流は通さず、交流は通す** |
| **ダイオード** | 電流を **一方向にだけ** 流す（整流）。発光するものが LED |
| **トランジスタ** | 小さな電流で大きな電流を制御する。**増幅** と **スイッチ** の働き |
| **パワー半導体** | 大きな電力の変換・制御（直流⇔交流、電圧の変換）を行う。エアコン、電気自動車のインバータに使う。SiC（炭化ケイ素）などの新素材で損失を減らす |

- **一致回路**：入力が同じときだけ1を出力する回路。XOR の出力を反転したもの（XNOR）。
- **NAND回路の組合せ**：NAND だけで AND・OR・NOT を作れる。NOT A ＝ A NAND A。
- **SRフリップフロップ**：S（セット）で1、R（リセット）で0を記憶し、両方を変化させなければ前の状態を保持する回路。NAND 2個をたすき掛けにつないで作る。
- **HDL（ハードウェア記述言語）**：FPGA などに実装するディジタル回路を、プログラムのような文で記述する言語（VHDL、Verilog HDL）。記述から直接、論理回路を合成できる。

### センサーの種類

| センサー | 測るもの |
|---|---|
| サーミスタ | 温度（温度で抵抗値が変わる） |
| フォトダイオード／フォトトランジスタ | 光の強さ |
| ポテンショメータ | 回転角度・位置 |
| 加速度センサー／ジャイロセンサー | 加速度・傾き／回転の速さ（角速度） |
| ドップラーセンサー | 物体の **速度**（反射波の周波数の変化を利用）。血流量の測定にも使う |
| ひずみゲージ | 力・重さによる変形 |

**自動車の先進運転支援システム（ADAS）のセンサー**：

| センサー | 特徴 |
|---|---|
| **可視光カメラ** | 天候の影響を受けやすいが、**色や形がわかるので交通標識や信号の認識に使える** |
| **ミリ波レーダー** | 電波を使う。雨や霧などの **天候の影響を受けにくく**、遠くの物体の距離と速度を測れる。色は判別できない |
| **LiDAR（レーザーレーダー）** | レーザー光で周囲を高精度に3次元測定する。悪天候には比較的弱い |
| **超音波センサー** | 数m程度の **近距離** の障害物検知（駐車支援など） |

### 組込み機器の制御

- **ウォッチドッグタイマ**：一定時間ごとにプログラムがタイマをクリアする仕組み。プログラムが暴走・停止してクリアされないまま時間が来ると、**異常とみなしてシステムをリセット** する。
- **汎用入出力ポート（GPIO）のビット操作**：ポートの各ビットが LED などに対応している。他のビットを変えずに、特定のビットだけを操作するには、次の論理演算を使う。

| やりたいこと | 演算 | 例（ビット2だけ操作） |
|---|---|---|
| 1にする（点灯） | 対象ビットが1のマスクと **OR** | ポート OR 00000100 |
| 0にする（消灯） | 対象ビットが0のマスクと **AND** | ポート AND 11111011 |
| 反転する | 対象ビットが1のマスクと **XOR** | ポート XOR 00000100 |

- **A/D変換の分解能**：8ビットの A/D 変換器は入力電圧を 2<sup>8</sup>＝256 段階で表す。0〜5V なら1段階は約 0.02V。
- **電池の駆動時間**：駆動時間 ＝ 電池の容量（mAh）÷ 平均消費電流（mA）。平均消費電流は「動作中の電流 × 動作時間の割合 ＋ 待機中の電流 × 待機時間の割合」で求める（令和5年度春期 午後問7で出題）。

:::calc 電池の駆動時間
容量 200mAh の電池。1分のうち、6秒だけ 20mA で動作し、残り54秒は 0.1mA で待機する。
平均消費電流 ＝ 20 × (6/60) ＋ 0.1 × (54/60) ＝ 2 ＋ 0.09 ＝ 2.09mA
駆動時間 ＝ 200 ÷ 2.09 ≒ **約96時間（約4日）**
:::

### 表示装置・その他

- **有機ELディスプレイ**：電圧をかけると **発光する** 有機化合物を使う。バックライトが不要で、薄く、曲げられるものもある。
- **液晶ディスプレイ**：液晶自体は発光せず、バックライトの光を通す量を制御する。
- **電子ペーパー**：電気泳動で白と黒の粒子を移動させて表示する。**表示を保つのに電力がほとんど不要**。
- **直流給電**：データセンタで、交流⇔直流の変換回数を減らして電力損失を小さくする。
- **耐タンパ性**：内部の情報を外部から不正に読み取ったり改ざんしたりされにくい性質（第9章）。
